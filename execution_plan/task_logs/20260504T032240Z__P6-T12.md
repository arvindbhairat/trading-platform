# P6-T12 — Stop interface + Fixed Stop

## Preconditions

- **Dependencies:** P6-T2 (RME module skeleton with `IStopLoss` interface, `StopLossInput`, `StopLossResult`)
- **Environment:** .NET 10, single worker process, Mongo + SQL Server available for integration tests

## REQ Coverage Attempted

- `portfolio-risk-guidelines.md § Stop Loss Types — Fixed Stop Loss`: Fixed Stop Loss — stop set at a fixed price below entry

## Actions Taken

1. **Created `apps/worker/Rme/FixedStopLoss.cs`** — concrete `IStopLoss` implementation:
   - `Name` = `"FixedStop"`
   - Reads `FixedStopPrice` from `AdditionalInputs`; falls back to `DefaultFixedStopDistancePct` from `RmeModuleOptions`
   - Validates stop price is below entry price (long-only platform guard); clamps to entry minus 1% if not
   - Rounds stop price to 2 decimal places
   - Stateless and thread-safe (singleton registration)

2. **Modified `apps/worker/Rme/RmeModuleOptions.cs`**:
   - Added `DefaultFixedStopDistancePct` (default `5.0`, range `0.1–50.0`) — default percentage below entry when no explicit stop price is provided

3. **Modified `apps/worker/Rme/RmeModuleExtensions.cs`**:
   - Registered `FixedStopLoss` as `IStopLoss` singleton
   - Injected `IEnumerable<IStopLoss>` into `RmeAdvisoryService`
   - Updated `GetSizingRecommendationAsync` to:
     - Resolve the stop model by `stopLossType` (falling back to `FixedStopLoss`)
     - Calculate stop price before sizing
     - Pass computed stop price to `SizingInput` (replacing the `StopPrice: 0m` placeholder)
     - Return computed stop price in `SizingAdvisory.StopPrice` (replacing the second `0m` placeholder)
     - Log stop type and stop price in the sizing advisory log line

4. **Updated `tests/worker/SignalStack.Worker.Tests/EquityBaseReaderTests.cs`**:
   - Added `FixedStopLoss` instance to `RmeAdvisoryService` constructor calls at two existing test sites
   - Updated stop type assertion from `"fixed_stop"` to `"FixedStop"` (matching the now-resolved stop model name)

5. **Created `tests/worker/SignalStack.Worker.Tests/FixedStopLossTests.cs`** — 9 unit tests:
   - Default distance calculation (5% below entry)
   - Explicit stop price from `AdditionalInputs`
   - Custom default distance from options
   - Clamping when explicit stop is above entry
   - Clamping when default stop equals entry
   - `Name` property
   - Rounding to 2 decimal places
   - Large entry price handling
   - Wrong-type `AdditionalInputs` value ignored (falls back to default)
