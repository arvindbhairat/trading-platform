## Actions Taken

### Backend — IntentSigningService (already implemented in prior session)
- Service reads HMAC key from `Execution:IntentHmacKey` config (Azure Key Vault sourced).
- Validates action, transaction type, product type (CNC enforced), quantity, order type, price.
- Re-checks hard blocks: kill switch, drawdown suppression for entry/add, duplicate in-flight for entry.
- Multi-intent portfolio heat gate (EC-5): sums existing open-position risk + pending intent estimated risk + proposed order risk; rejects if exceeding `risk.default.max_portfolio_heat_pct` (default 5%).
- LADS health gate (RME-R2): checks `rme_incidents` for open `lads_sustained_failure`; if active, rejects with last successful sync timestamp.
- Generates 16-byte cryptographically random nonce.
- Builds canonical payload with domain separation prefix `fyers.intent.v1:` and computes HMAC-SHA256 + SHA256 payload hash.
- Returns `SignedPayloadResponse` with nonce, data attributes, payload hash, and expiry.
- Verifies position exists for SELL actions (reduce/exit).

### Dependency registration — ExecutionExtensions.cs

### Fix: Mongo mock compatibility (7 failing tests — this session's work)
- Tests were failing with `NullReferenceException` at `IAsyncCursorExtensions.GetFirstBatchAsync` on all BUY-path tests.
- **Root cause:** `ReadEquityAsync` and `ReadHighWaterMarkAsync` used the fluent `Find().Sort().Limit()` builder, which returns `IFindFluent` — its `ToCursorAsync` branches on `IClientSessionHandle`, and the mock's `FindAsync` setup was not matching the internal call path.
- **Fix:** Refactored both methods to call `FindAsync` directly with explicit `FindOptions<BsonDocument, BsonDocument>`, and replaced `FirstOrDefaultAsync(ct)` with manual cursor iteration (`MoveNextAsync(ct)` + `Current.FirstOrDefault()`).
- **Mock fix:** Corrected test cursor mocks — `SetupSequence` for multi-return cursors (kill switch test and SELL parameterized test), `Setup` for single-return cursors (BUY paths in MockEmptyCollection). Explicit `<BsonDocument>` type parameter on all `FindAsync` mock setups.
- All 20 tests now pass (17 IntentSigningService + 3 supporting).
