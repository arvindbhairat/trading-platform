## Actions Taken

### API (C#)

1. **`IFyersTokenRepository.cs`** — Added `GetAccessTokenAsync(string userId, CancellationToken)` method to expose raw FYERS access token for browser-tier WebSocket use.

2. **`MongoFyersTokenRepository.cs`** — Implemented `GetAccessTokenAsync` by finding the active token document and returning its `AccessTokenRef`.

3. **`FyersAuthService.cs`** — Added `GetAccessTokenAsync` service method that delegates to repository. Updated `SimulateCallbackAsync` to generate a real-looking simulated token value (`sim_{userId}_{hex}`) instead of a KV reference, so the browser-tier WebSocket can use it in local dev.

4. **`FyersEndpoints.cs`** — Added two new endpoints:
   - `GET /api/v1/fyers/token` — Returns the user's active FYERS access token for browser WebSocket use (RequireAuthorization, GET-only, no CSRF).
   - `GET /api/v1/fyers/quotes?symbols=NSE:SBIN-EQ,NSE:RELIANCE-EQ` — Proxies FYERS REST quotes API using the user's token for REST fallback when WebSocket is down (RequireAuthorization, GET-only, no CSRF).

5. **`Program.cs`** — Registered `IHttpClientFactory` via `AddHttpClient("FyersApi", ...)`. Updated CSP header to allow `connect-src 'self' https://api-t1.fyers.in wss://socket.fyers.in` plus `img-src` and `style-src` for chart rendering.

### Frontend (TypeScript)

6. **`package.json`** — Added `lightweight-charts: ^4.2.0` dependency.

7. **`src/lib/live-quotes.ts`** — Created the core `LiveQuotesClient` class:
   - Connects to FYERS Data WebSocket (`wss://socket.fyers.in/data/v3`) using the user's token fetched from `GET /api/v1/fyers/token`
   - Authenticates with FYERS format `appId:token`
   - Subscribes to symbols with `SymbolUpdate` data type
   - Handles FYERS message types (`sf` = equity, `if` = index)
   - REST fallback: polls `GET /api/v1/fyers/quotes?symbols=...` at configured interval when WebSocket disconnects
   - PLD lease: connects to `/ws/pld?token=JWT`, monitors close code 4001 for eviction
   - Data freshness tracking per-symbol and overall
   - Singleton instance via `getLiveQuotes()` for cross-component sharing

8. **`src/app/(user)/chart/page.tsx`** — Created the chart page:
   - Symbol search with auto-prefixing (`NSE:`/`-EQ`)
   - TradingView `lightweight-charts` candlestick chart with timeframes (daily/weekly/monthly)
   - Live price header with change/change% in up/down colors
   - PLD connection status indicator (Pill component with dot)
   - Eviction banner when another tab takes over (close code 4001)
   - REST fallback warning banner (REQ-STOP-006c)
   - Data freshness timestamp "Data as of: {HH:MM:SS} IST" (REQ-DASH-013)
   - RME advisory panel (stubbed, follows design system reference)
   - "Review on FYERS" external link button
