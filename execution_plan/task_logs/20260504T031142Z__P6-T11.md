## Actions Taken

1. **Created `DrawdownAdjustedSizingModel.cs`** (`apps/worker/Rme/`):
   - Implements `ISizingModel` following the same strategy pattern as `FixedPercentageSizingModel`, `AtrSizingModel`, and `HeatBasedSizingModel`.
   - Name: `"DrawdownAdjusted"`.
   - Input: `CurrentDrawdownPct` extracted from `SizingInput.AdditionalInputs`.
   - Formula: base risk = equity × riskPct; if drawdown ≤ reductionStart → factor = 1.0; if drawdown ≥ blockPct → factor = 0.0 (blocked); else linear interpolation between start and block. Adjusted risk = baseRisk × factor. Quantity = floor(adjustedRisk / stopDistance).
   - Stateless, thread-safe, registered as singleton.

2. **Updated `RmeModuleOptions.cs`** — added two configurble properties:
   - `DrawdownReductionStartPct` (default 5.0, range 0.0–100.0) — threshold where linear reduction begins.
   - `DrawdownBlockPct` (default 20.0, range 0.0–100.0) — threshold where new entries are blocked.

3. **Updated `RmeModuleExtensions.cs`** — registered `DrawdownAdjustedSizingModel` as singleton `ISizingModel`.

4. **Created `DrawdownAdjustedSizingModelTests.cs`** (`tests/worker/SignalStack.Worker.Tests/`) — 18 tests covering:
   - No drawdown → full size
   - Drawdown below reduction start → full size
   - Drawdown at reduction start → full size
   - Drawdown above reduction start → reduced size (proportional)
   - Drawdown at midpoint → 50% reduction
   - Drawdown at block threshold → zero quantity
   - Drawdown above block threshold → zero quantity with advisory
   - Missing drawdown input → treated as 0 (no reduction)
   - Custom reduction start, block pct, risk pct from options
   - Large equity, small equity, very small equity
   - Invalid stop distance (entry price as proxy)
   - Negative drawdown → treated as 0
   - Missing stop price → entry price proxy
   - Name property
