### 3. Created `TimeStopRecomputeService`

**File:** `apps/api/Admin/TimeStopRecomputeService.cs`

- Singleton service injectable by the API (connected to `IMongoDatabase`, `ITradingCalendarRepository`, `INotificationWriter`, `ILogger`)
- `ComputeTimeStopDateAsync(string entryDate, int sessionCount)` — core calendar-aware date computation:
  - Fetches trading sessions from the calendar repository
  - Finds the first session after the entry date
  - Counts N sessions forward: `sessions[firstAfterIndex + sessionCount - 1]`
  - Extended query fallback when initial buffer is insufficient
- `RunRecomputeAsync()` — debounced recompute orchestrator:
  - Loads `risk.time_stop.default_sessions` from `sys_config` (fallback 10)
  - Queries all non-terminal positions with non-null `time_stop_date`
  - For each: computes new date, batches OCC-safe `$set` + `$push` (audit entry) operations
  - Writes `rme_events` records (`event_type: time_stop_recomputed_on_calendar_edit`)
  - Emits single admin summary notification via `INotificationWriter`
- `Trigger()` — fire-and-forget with 5-second debounce window

### 4. Wired recompute to calendar CRUD endpoints
