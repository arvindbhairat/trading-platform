## Actions taken

- Added shared logging redaction primitives under `packages/config/SignalStack.Configuration/Logging/`.
- Implemented a case-insensitive sensitive-name matcher covering `token`, `access_token`, `authorization`, `secret`, `password`, `api_key`, and `apikey`.
- Added a Serilog enricher that rewrites matching `LogEvent` properties to the literal `[REDACTED]` while preserving the original property name.
- Added an OpenTelemetry log processor that rewrites matching exported log attributes to `[REDACTED]` before OTLP export.
- Added a shared Serilog logger configuration helper that applies the redaction enricher, preserves `ILogger` usage, and maps the existing `Logging:LogLevel` section into Serilog minimum-level configuration.
- Wired both `apps/api` and `apps/worker` to:
  - clear default MEL providers,
  - add Serilog as a logging provider,
  - keep traces and metrics on the existing OpenTelemetry path,
  - export logs through OpenTelemetry with the shared redaction processor in front of the OTLP exporter.
- Added a focused API test file covering:
  - Serilog sink redaction for a `LogEvent` carrying `access_token`,
  - OpenTelemetry attribute redaction for the same property name.
- Because new package restore from `nuget.org` is blocked in this sandbox, replaced the new Serilog/OpenTelemetry additions with direct assembly references to the already-cached local NuGet package contents via `$(USERPROFILE)\.nuget\packages\...`, keeping the source buildable offline in this environment.
