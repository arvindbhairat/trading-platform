### Actions Taken

1. **SessionDocument.cs** — Added `MfaVerifiedAt` (nullable DateTime) field to record when an admin's MFA was verified (REQ-BCP-009).

2. **ISessionRepository.cs** — Added optional `DateTime? mfaVerifiedAt = null` parameter to `CreateSessionAsync` signature.

3. **MongoSessionRepository.cs** — Updated `CreateSessionAsync` to pass `mfaVerifiedAt` to the `SessionDocument` constructor.

4. **IUserRepository.cs** — Added `UpsertAdminOnSignInAsync` method that atomically creates or promotes a user to admin role + approved status.

5. **MongoUserRepository.cs** — Implemented `UpsertAdminOnSignInAsync` using MongoDB `UpdateOneAsync` with `IsUpsert = true`. On insert: creates with `role=admin`, `status=approved`. On update: always sets `role=admin`, `status=approved` so that a deactivated admin re-activates on matching seed email sign-in.

6. **AuthEndpoints.cs** — Modified the OAuth callback handler (`/callback/{provider}`) to:
   - Read `SEED_ADMIN_EMAIL` from bootstrap configuration (`Auth:SeedAdminEmail` or `SEED_ADMIN_EMAIL`)
   - Block Facebook sign-in for the admin email with `admin_provider_restricted` error (REQ-ROLE-007)
   - Validate `amr` claims for admin sign-in; block without MFA with `admin_mfa_required` error (REQ-BCP-009)
   - Call `UpsertAdminOnSignInAsync` for seed admin or `UpsertOnSignInAsync` for regular users (REQ-ROLE-005)
   - Pass `mfaVerifiedAt` to session creation for admin users

7. **InMemorySessionRepository.cs** — Updated `CreateSessionAsync` to handle `mfaVerifiedAt` parameter.

8. **InMemoryUserRepository.cs** — Added `UpsertAdminOnSignInAsync` implementation.

9. **AuthTestApiFactory.cs** — Added `Auth:SeedAdminEmail = "admin@signalstack.test"` to test configuration.

10. **AdminBootstrapTests.cs** — Created 6 new tests covering:
    - UpsertAdminOnSignInAsync creates admin role + approved status
    - Admin user session status returns `fyers_required` (bypasses pending_approval)
    - Idempotent upsert (second call preserves admin role)
    - Promotion from regular user to admin
    - Admin session records `MfaVerifiedAt`
    - Regular user session has null `MfaVerifiedAt`

11. **SignalStack.Migrations stub** — Created a minimal migration project stub (`packages/migrations/SignalStack.Migrations/`) to satisfy the API project's project reference.
