## Actions taken

- Refactored `apps/worker` from a single-file sample into a small baseline host with:
  - `WorkerHeartbeatService` for the running heartbeat loop.
  - `WorkerSingletonCoordinator` for startup self-election and lease refresh decisions.
  - `RedisWorkerSingletonLeaseBackend` for the Redis-backed singleton lease flow keyed by `rme:worker:singleton`.
  - `WorkerSingletonOptions` for lease key, TTL, refresh cadence, and heartbeat cadence.
- Added startup behaviour matching the task slice:
  - successful lease acquisition allows the worker heartbeat loop to run;
  - lease conflict logs `singleton_violation` and stops the process with a non-zero exit code;
  - Redis unavailability logs `singleton_lease_unavailable` and allows startup to continue.
- Added Worker test project coverage for the runtime self-election decisions.
- Added Azure App Service worker IaC at `infra/azure/worker-appservice.bicep` with `workerCount = 1` and no autoscale resource.
- Added deployment preflight script `infra/azure/scripts/Test-WorkerSingletonPreflight.ps1` that fails when the target App Service plan capacity is not 1 or when an autoscale rule is attached.
- Added GitHub Actions workflow `/.github/workflows/worker-release-preflight.yml` to run the preflight check before Worker release promotion.
- Updated the solution file to include the Worker tests project.
