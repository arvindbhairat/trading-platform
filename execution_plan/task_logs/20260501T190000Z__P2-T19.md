## Actions Taken

### API (apps/api)

1. **Created `Admin/JobRunDocument.cs`** — MongoDB document model for the `job_runs` collection. Fields: `job_type`, `trigger_source`, `scheduled_run_time`, `started_at`, `ended_at`, `outcome`, `symbols_processed`, `errors`, `depends_on`.

2. **Created `Admin/AdminHomeEndpoints.cs`** — Two admin API endpoints:
   - `GET /api/v1/admin/transfer-recovery-summary` — Returns the transfer recovery summary for the current admin. Queries `job_runs` for failed/skipped runs in the transfer window (from last successful job run before restart to now). Also checks admin FYERS token status. Returns empty/no-review data when nothing needs attention. Respects prior dismissal via `audit_events`.
   - `POST /api/v1/admin/transfer-recovery-summary/dismiss` — Records a `transfer_recovery_dismissed` audit event so the summary is not shown again.

3. **Extended `Audit/IAuditEventRepository.cs`** — Added `HasEventAsync(actorId, actionType)` method to check for existing audit events by actor and type.

4. **Extended `Audit/MongoAuditEventRepository.cs`** — Implemented `HasEventAsync` using MongoDB `AnyAsync` filter query.

5. **Updated `Program.cs`** — Registered `app.MapAdminHomeEndpoints()`.

### Frontend (apps/web)

6. **Created `apps/web/src/app/admin/page.tsx`** — Admin home page with:
   - Transfer recovery summary card (shown when `needsReview && !dismissed`):
     - Lists failed/skipped job runs in a table with job type, scheduled time, outcome pill, and one-click "Retry" action button
     - FYERS token missing notice with "Authenticate with FYERS" button linking to `POST /api/v1/fyers/auth/init`
     - "Dismiss summary" button that calls `POST /api/v1/admin/transfer-recovery-summary/dismiss` and hides the card
   - Standard dashboard content below (placeholder cards for System health and Platform overview, to be filled by P5/P8 infra)
   - Follows existing admin page patterns: `Shell`, `Card`, `Btn`, `Pill`, `Icon`, design tokens, `apiFetch`/`getToken` auth helpers.

7. **Fixed pre-existing type error** in `apps/web/src/app/admin/privacy-requests/page.tsx` — `STATUS_PILL_TONE` type was missing `"brand"` from its union type, causing a build failure.
