## Actions Taken

1. **Created CorporateActionDetectedEvent model** in `apps/worker/Rme/RmeEvent.cs` — carries FYERS vs FIFO comparison data (FyersQuantity, FyersAvgCost, FifoQuantity, FifoAvgCost, DeltaPercent).

2. **Created CorporateActionDetectionService** (`apps/worker/Jobs/AccountSync/CorporateActionDetectionService.cs`) — compares FYERS-reported holdings against FIFO-derived holdings per-user. Detects quantity mismatches (any non-zero difference) and average cost deltas exceeding a configurable threshold (sys_config key `risk.corporate_action.avg_cost_delta_threshold_pct`, default 50%). Returns `CorporateActionDiscontinuity` results.

3. **Created CorporateActionDetectionModels** (`apps/worker/Jobs/AccountSync/CorporateActionDetectionModels.cs`) — `FyersHolding` record for FYERS input data and `CorporateActionDiscontinuity` record for detected discontinuity results.

4. **Wired CA detection into LADS sync** (`apps/worker/Jobs/AccountSync/LiveAccountDataSyncService.cs`) — Added `CorporateActionDetectionService` as DI dependency. In `SyncUserAccountAsync` Step 2b: after trade ingestion, runs CA detection, finds Open positions matching discontinuity symbols, enqueues `CorporateActionDetectedEvent` through the per-position channel registry.

5. **Wired CorporateActionDetectedEvent in RmeEventConsumer** (`apps/worker/Rme/RmeEventConsumer.cs`) — Added `CorporateActionDetectedEvent => TransitionReason.CorporateActionDetected` to `MapReason()`. Added formatted advisory message with FYERS/FIFO comparison details.

6. **Updated incident_type switch in PositionChannelRegistry** (`apps/worker/Rme/PositionChannelRegistry.cs`) — Added `"corporate_action_detected" => "corporate_action_suspension"` to the incident_type switch in `WriteIncidentFromOutput`.

7. **Added notification writing on CA suspension** (`apps/worker/Rme/PositionChannelRegistry.cs`) — Injected `INotificationWriter`. Changed `ApplyOutputs` to async (`ApplyOutputsAsync`) with cancellation token. Added `WriteCaNotificationsAsync` that writes both a user-facing `corporate_action_warning` notification and an admin `admin_corporate_action_discontinuity` notification when a CA suspension transition is applied.

8. **Built admin re-anchor endpoint** (`apps/api/Admin/AdminPositionEndpoints.cs`) — Added `POST /api/v1/admin/positions/{positionId}/reanchor`. Step-up gated. Validates position is Suspended with an open `corporate_action_suspension` incident record. Accepts corrected quantity and entry price. Writes audit event (step-up linked), updates position with re-anchored values, transitions to Open (or PendingEntry if entry_price is zero), closes the incident record.

9. **Added CA warning flag to portfolio holdings** (`apps/api/Portfolio/PortfolioEndpoints.cs`, `apps/api/Portfolio/Holding.cs`) — Added `corporate_action_warning_active` boolean to the holdings endpoint response. Added `GetCaSuspensionSymbolsAsync` helper that queries positions → rme_incidents to identify symbols with open CA suspension incidents.
