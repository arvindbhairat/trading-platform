4. Created `SwingLowStopLossTests.cs` with 17 tests covering:

   - Custom buffer from options (1.0%).
   - Missing / zero / negative swing low (fallback).
   - Swing low at entry / above entry (fallback).
   - Larger buffer (2.0%) produces lower stop.
   - Smaller buffer (0.1%) produces higher stop.
   - Clamping when explicit stop >= entry.
   - Clamping when fallback equals entry.
   - Name property.
   - Rounding to two decimals.
   - Large entry price.
   - Wrong-type AdditionalInputs ignored.
