## Actions Taken

### 1. Shared DDL template (`packages/migrations/SignalStack.SqlMigrations/SharedTableDdlTemplate.cs`)
- Created the shared DDL template for per-symbol OHLCV tables per REQ-HIST-009a(c).
- `CreateTableIfNotExists(tableName)` generates CREATE TABLE with `IF NOT EXISTS` semantics (REQ-HIST-009a(a)).
- `CreatePerSymbolTablesAsync()` creates all three tables (D_, W_, M_) inside a single transaction for per-symbol atomicity (REQ-HIST-009a(b)).
- Schema: Date (DATE), Open (FLOAT), High (FLOAT), Low (FLOAT), Close (FLOAT), Volume (BIGINT) — REQ-HIST-002.
- Index on Date for efficient range queries.

### 2. `ISymbolTableMapping` interface (`apps/api/Historical/ISymbolTableMapping.cs`)
- Single shared mapping service per REQ-HIST-011.
- Methods: `GetTableNamesAsync()`, `GetSuffixAsync()`, `GetAllSuffixesAsync()`, `RefreshAsync()`.
- Static `TimeframePrefix()` helper maps timeframe names to D_/W_/M_ prefixes.
- REQ-HIST-003: full table names constructed by prepending timeframe prefix to suffix.
- REQ-HIST-004: tables referenced by sql_table_name_suffix, not symbol text.

### 3. `SymbolTableMappingService` (`apps/api/Historical/SymbolTableMappingService.cs`)
- In-memory ConcurrentDictionary loaded from MongoDB `symbol_master` at startup.
- Thread-safe: read-heavy, write-rare (refresh only on universe sync).
- `InitializeAsync()` called from Program.cs startup; `RefreshAsync()` available for after Universe Sync.
- REQ-HIST-008: suffix is stable; REQ-HIST-011: single source of truth.

### 4. `IOhlcvRepository` interface + `OhlcvRecord` (`apps/api/Historical/IOhlcvRepository.cs`)
- Methods: `GetDailyAsync()`, `GetWeeklyAsync()`, `GetMonthlyAsync()`, `GetRollingAsync()`, `GetLastCandleDateAsync()`.
- Rolling window candles computed on demand per REQ-TIMEFRAME-006.
- REQ-TIMEFRAME-003: rolling candle Open is oldest session, Close is most recent.

### 5. `SqlOhlcvRepository` (`apps/api/Historical/SqlOhlcvRepository.cs`)
- SQL Server implementation reading from D_, W_, M_ tables using ISymbolTableMapping for table name resolution.
- Rolling candle computation: fetches N most recent D_ sessions, aggregates into single OHLCV record.
- Last-candle-date query checks table existence first before querying MAX(Date).

### 6. `WeeklyCandleBoundary` (`apps/api/Historical/WeeklyCandleBoundary.cs`)
- Single authoritative weekly boundary implementation per REQ-HIST-010a(d).
- `GetIsoWeek()`: ISO 8601 week assignment for Asia/Kolkata (REQ-HIST-010a(a)).
- `ComputeWeeklyCandle()`: aggregates multiple sessions into weekly OHLCV; handles single-session weeks (REQ-HIST-010a(b)).
- `AggregateToWeekly()`: groups daily records by ISO week and produces weekly candles.
- Cross-week Muhurat sessions (REQ-HIST-010a(c)) handled correctly by standard ISOWeek implementation.

### 7. Chart API endpoints (`apps/api/Historical/ChartEndpoints.cs`)
- `GET /api/v1/chart/{symbol}?timeframe=daily&from=...&to=...` — returns OHLCV data
- `GET /api/v1/chart/{symbol}/last` — returns most recent candle date
- `GET /api/v1/chart/{symbol}/rolling?window=5&to=...` — returns rolling N-session candle
- Validates symbol existence via ISymbolTableMapping before querying SQL Server.
- Valid timeframe values: daily/weekly/monthly (or d/w/m).

### 8. DI registration (`apps/api/Historical/HistoricalExtensions.cs`)
- `AddHistoricalServices(sqlConnectionString)` registers ISymbolTableMapping (singleton) and IOhlcvRepository (singleton with SQL connection).
- Falls back to NoopOhlcvRepository when SQL connection string is not configured.
- `InitializeHistoricalServicesAsync()` loads the symbol mapping cache at startup.

### 9. Program.cs wiring
- Added `using SignalStack.Api.Historical;`
- Added `builder.Services.AddHistoricalServices(sqlConnectionString)` after trading calendar management.
- Added `app.MapChartEndpoints()` before app.Run().
- Added `await app.InitializeHistoricalServicesAsync()` before app.Run().
- Updated version string from `v0.3` to `v0.4`.

### 10. Test infrastructure
- `InMemorySymbolTableMapping` — test double with configurable symbol→suffix mappings.
- `InMemoryOhlcvRepository` — test double with seeded data per symbol and timeframe.
- `WeeklyCandleBoundaryTests` — 13 tests covering all four REQ-HIST-010a rules.
- `ChartEndpointsTests` — 8 integration tests covering all three endpoints, valid/invalid symbols, timeframes.
