## Actions taken

### 1. User model changes
- Added `LinkedIdentities` (List&lt;LinkedIdentity&gt;?) and `LinkedIdentity` record to `UserDocument`
- `LinkedIdentity` has: `Provider`, `ProviderKey`, `Email`, `LinkedAt`

### 2. Repository interface (`IUserRepository`)
- Added `FindByLinkedIdentityAsync(provider, providerKey)` — finds user by secondary identity
- Added `LinkIdentityAsync(userId, provider, providerKey, email)` — links secondary identity (max 2)
- Added `UnlinkIdentityAsync(userId, provider, providerKey)` — removes a linked identity
- Added `RebindIdentityAsync(targetUserId, newProvider, newProviderKey, newEmail)` — admin-assisted full rebind

### 3. MongoDB implementation (`MongoUserRepository`)
- `FindByLinkedIdentityAsync`: uses `ElemMatch` filter on `LinkedIdentities` array
- `LinkIdentityAsync`: checks cross-user uniqueness, reads current list, enforces max-2, `$push`
- `UnlinkIdentityAsync`: `PullFilter` by provider+providerKey
- `RebindIdentityAsync`: `FindOneAndUpdateAsync` changes `UserId`, `Provider`, `Email`, clears `LinkedIdentities`

### 4. Auth endpoints (`AuthEndpoints.cs`)
- **Linking flow (OAuth callback)**: detects `link=true` + nonce in OAuth Properties, calls `LinkIdentityAsync`, writes audit event, redirects to `settings?link=success`
- **Linked identity sign-in**: after linking check, uses `FindByLinkedIdentityAsync`, signs in as the linked account's user (cross-account JWT issued)
- **`POST /api/v1/auth/link/init`**: generates nonce, returns `link_url` with provider
- **`GET /api/v1/auth/linked-identities`**: returns primary and linked identities with masked emails
- **`POST /api/v1/auth/linked-identities/unlink`**: checks not unlinking primary, calls `UnlinkIdentityAsync`, writes audit
- **`POST /api/v1/auth/admin/recover`**: admin-only, step-up gated, calls `RebindIdentityAsync`, captures before/after state in audit

### 5. Helper types
- `LinkNonce` record, `LinkNonceTtl = 5 min`, `_linkNonces` ConcurrentDictionary
- `UnlinkRequest`: `string Provider, string ProviderKey`
- `AdminRecoverRequest`: `string TargetUserId, string NewProvider, string NewProviderKey, string? NewEmail, List<string?>? VerificationItems`
- `EmailMask` static class with `Mask(string email)` method

### 6. Test support (`InMemoryUserRepository`)
- Added `FindByLinkedIdentityAsync`, `LinkIdentityAsync`, `UnlinkIdentityAsync`, `RebindIdentityAsync`
- Fixed `init`-only property issues with `CloneWith` helper and full constructor-style rebuild for `RebindIdentityAsync`
