## Actions Taken

1. **Created `Timeframe.cs`** — First-class shared `Timeframe` record with static definitions for all six timeframes (daily, weekly, monthly, rolling3, rolling5, rolling7). Includes `Name`, `DisplayName`, `IsRolling`, `WindowSize`, `SqlTablePrefix` properties. `TryParse()` and `Parse()` for case-insensitive resolution. REQ-TIMEFRAME-001/004.

2. **Created `ITimeframeService.cs` + `TimeframeService.cs`** — Service interface and calendar-aware implementation. Resolves timeframes by name (including short aliases: d/w/m/3/5/7). Provides `GetAll()`, `GetStandardTimeframes()`, `GetRollingTimeframes()`, `Resolve()`. `GetLastNSessionDatesAsync()` queries the trading calendar for session-aware date windows (REQ-TIMEFRAME-002, REQ-CALENDAR-003).

3. **Updated `ChartEndpoints.cs`** — Removed hardcoded `ValidTimeframes` HashSet. Uses `ITimeframeService.Resolve()` for validation and resolution. Main `GetChartDataAsync` endpoint now accepts rolling3/5/7 timeframe values and routes them to `GetRollingAsync()` with the correct window size. Kept legacy `GET /{symbol}/rolling?window=N` endpoint for backward compatibility.

4. **Updated `HistoricalExtensions.cs`** — Registered `ITimeframeService` / `TimeframeService` as singleton in DI container.

5. **Updated `chart/page.tsx`** — Added `STANDARD_TIMEFRAMES` and `ROLLING_TIMEFRAMES` arrays. Updated type union to include `rolling3 | rolling5 | rolling7`. Simplified `loadHistoricalData` to pass timeframe directly as query param. Added separator between standard and rolling timeframe buttons.

6. **Updated `signals/page.tsx`** — Added rolling3/5/7 to the TIMEFRAMES constant for Signal Subscription creation.

7. **Updated `SignalSubscriptionDocument.cs`** — Documented rolling timeframes as valid values in the `Timeframe` field XML doc.

8. **Added `InMemoryTradingCalendarRepository.cs`** — Test double for calendar repo, following existing InMemory pattern.

9. **Added `TimeframeTests.cs`** — 13 unit tests covering all six timeframe definitions, parsing, case-insensitivity, alias resolution, and service methods.

10. **Added rolling timeframe tests to `ChartEndpointsTests.cs`** — Tests for rolling3/5/7 through the main chart endpoint, invalid timeframe, and short alias `d`.

11. **Updated `TestApiFactory.cs`** — Registered `InMemoryTradingCalendarRepository` to replace MongoDB-backed repo in tests.
