## Actions taken

1. **Created `AtrSizingModel`** (`apps/worker/Rme/AtrSizingModel.cs`):
   - Implements `ISizingModel` with `Name = "AtrBased"`.
   - Reads ATR value from `SizingInput.AdditionalInputs["ATR"]` (decimal).
   - Applies formula: `riskAmount = equity × (riskPct / 100)`, `stopDistance = ATR × AtrMultiplier`, `RecommendedQuantity = floor(riskAmount / stopDistance)`.
   - Logs warnings when ATR is missing, zero, or negative (returns zero quantity with advisory).
   - Stateless, thread-safe, singleton-safe.

2. **Extended `RmeModuleOptions`** (`apps/worker/Rme/RmeModuleOptions.cs`):
   - Added `AtrMultiplier` property (default 2.0, range 0.5–10.0).

3. **Registered in DI** (`apps/worker/Rme/RmeModuleExtensions.cs`):
   - Added `services.AddSingleton<ISizingModel, AtrSizingModel>()` under a new P6-T9 comment section.

4. **Wrote unit tests** (`tests/worker/SignalStack.Worker.Tests/AtrSizingModelTests.cs`):
   - 11 tests covering: standard ATR sizing, missing ATR (zero quantity + advisory), zero ATR, negative ATR, wide ATR (high volatility → small qty), narrow ATR (low volatility → large qty), custom multiplier, custom risk percentage, large equity (10 Cr), small equity (fractional floor), and Name property.
