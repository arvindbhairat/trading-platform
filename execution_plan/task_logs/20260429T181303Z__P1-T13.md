## REQ Coverage Attempted
- REQ-PORT-031 — per-user Redis lock; lock key format; UUID token; TTL from `jobs.ledger_lock.ttl_seconds`; acquisition modes; non-blocking/timed/blocking semantics; renewal interval from `jobs.ledger_lock.renewal_interval_seconds`.
- REQ-PORT-031a — `ledger_snapshot_version` helper interface; invariant: increment only after durable commit; interface contract documented with inline invariant list.
- REQ-PORT-031b — Redlock single-node trade-off documented; fencing token via Redis INCR on `ledger:write:fence:{userId}`; fencing-token abort path does not advance `ledger_snapshot_version` (invariant A-11); Redis DB index separation (`LOCK_DB_INDEX` noeviction vs cache DB); Lua-guarded release/renew.
