## REQ Coverage Attempted

## Actions Taken

1. **Extended `IAuditEventRepository`** with:
   - `AuditEventFilter` record (ActorId, ActionType, From, To filters)
   - `ListAsync(filter, page, pageSize, ct)` — paginated query with filtering
   - `GetByIdAsync(id, ct)` — single document lookup

2. **Implemented in `MongoAuditEventRepository`**:
   - `ListAsync` with MongoDB `CountDocumentsAsync` + paginated `Find` sorted by `event_at` descending
   - `GetByIdAsync` via `Find(e => e.Id == id).FirstOrDefaultAsync`
   - `BuildFilterDefinition` helper composing optional actor_id / action_type / date-range filters

3. **Created `AdminAuditEndpoints.cs`**:
   - `GET /api/v1/admin/audit-events` — paginated list with optional `?actor_id=`, `?action_type=`, `?from=`, `?to=`, `?page=`, `?page_size=` query params
   - `GET /api/v1/admin/audit-events/{id}` — single event detail
   - Admin role check via `IUserRepository` (matching existing admin endpoint pattern)
   - Pagination clamping (page >= 1, page_size 1-200)

4. **Wired endpoints in `Program.cs`** via `app.MapAdminAuditEndpoints()`

5. **Added retention sys_config key** in `SysConfigManifest.cs`:
   - `retention.audit_events.archive_threshold_days` (default 730 / 24 months)

6. **Updated `InMemoryAuditEventRepository`** with:
   - `ListAsync` and `GetByIdAsync` implementations
   - `Clear()` method for test isolation

7. **Created `AdminAuditEndpointTests.cs`** (8 tests):
   - Paginated results return correct page/page_size/total_count/total_pages
   - Filter by action_type returns only matching events
   - Filter by actor_id returns only matching events
   - Empty response when no events match
   - Get by existing ID returns the event
   - Get by missing ID returns 404
   - Get by invalid ID format returns 400
   - Non-admin user receives 403
