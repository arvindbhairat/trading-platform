## Actions Taken

1. Created `TradingCalendarDocument.cs` — MongoDB document model for the `trading_calendar` collection with fields: `session_date`, `session_type` (normal/special/muhurat/non_trading_day), `session_start_time`, `session_end_time` (IST), `holiday_name` (optional, for non-trading-day markers), timestamps.

2. Created `ITradingCalendarRepository.cs` — Repository interface with methods: GetAllAsync, FindByDateAndTypeAsync, FindByDateAsync, GetSessionsAsync, GetNonTradingDaysAsync, CreateAsync, UpdateAsync, DeleteAsync, CountAsync.

3. Created `MongoTradingCalendarRepository.cs` — MongoDB implementation using `IMongoCollection<TradingCalendarDocument>` on the `trading_calendar` collection. Supports date range filtering, session type filtering, and composite filters.

4. Created `IstTimeZone.cs` — Cross-platform timezone resolver for Asia/Kolkata (IANA → Windows fallback).

5. Created `TradingCalendarEndpoints.cs` — Admin CRUD endpoints under `/api/v1/admin/calendar/`:
   - GET `/` — list entries with optional `?from=`, `?to=`, `?sessionType=` filters
   - GET `/{date}` — find entries for a specific date
   - POST `/` — create entry with type-specific validation (session times required for sessions, prohibited for non-trading-day)
   - PUT `/{id}` — update mutable fields
   - DELETE `/{id}` — delete entry

6. Created `TradingCalendarExtensions.cs` — DI registration extension method `AddTradingCalendarManagement()`.

7. Wired into `Program.cs`: DI registration (`builder.Services.AddTradingCalendarManagement()`) and endpoint mapping (`app.MapTradingCalendarEndpoints()`).

8. Created `apps/web/src/app/admin/calendar/page.tsx` — Full admin UI with:
   - Calendar entries table (Date, Type, Start/End IST, Holiday, Actions)
   - Date range filters (from/to) and session type filter
   - Add entry form with type selector, conditional fields (start/end time for sessions, holiday name for non-trading-day)
   - Edit and Delete operations
   - Notification banners for success/error

9. Added `jobs.eod_sync.default_time_ist` to both `SysConfigManifest.cs` (seed entry: string, "17:00", REQ-CALENDAR-004) and `docs/system-config.md` Required Seed Table.

10. The nav item `{ id: "calendar", label: "Trading calendar", icon: "calendar" }` already existed in `primitives.tsx` from prior work — no change needed.
