## REQ Coverage Attempted
- **REQ-PYR-003** — Maximum add-on entries per position configurable (`risk.pyramiding.max_addon_entries`, sys_config default 3). Enforced in `PyramidingAdvisoryService.Evaluate()`.
- **REQ-PYR-011** — Never-lowers-stop floor invariant. When a new pyramid tranche is added and the recalculated combined stop is lower than the highest individual tranche stop, the highest existing stop is preserved as the floor. Implemented in `ComputeCombinedStop()` and `Evaluate()`.
- **REQ-SIZING-007** — Z-score default timeframe (`rolling_5d`), add-more threshold (+3), reduce-size threshold (-3). Implemented in `ZScoreAdvisoryService.ComputeAdvisory()`.
- **Coverage also includes:**
  - REQ-PYR-004 (progressive add-on quantity reduction — `ComputeAddonQuantity`)
  - REQ-PYR-010 (recalculate avg entry, combined stop, R multiple after add/reduce — `Evaluate` output fields)

- Interface for evaluate add/reduce, compute combined stop, compute avg entry price, compute R multiple, compute add-on quantity.

- Full implementation: add trigger evaluation at configured % from avg entry, reduce trigger at 3R profit target, max add-on enforcement, progressive add-on quantity reduction (`ComputeAddonQuantity`), never-lowers-stop floor (`ComputeRawWeightedStop`/`ComputeCombinedStop`), average entry price and R-multiple computation.

### 6. Created `IZScoreAdvisoryService.cs`
- Interface for computing z-score advisory from closing prices.

### 7. Created `ZScoreResult.cs`
- `ZScoreAdvisory` record with ZScore, AddThreshold, ReduceThreshold, Timeframe, SampleCount, Mean, StandardDeviation, AddPriceLevel, ReducePriceLevel, AddAdvisory, ReduceAdvisory, AdvisoryMessage.

### 8. Created `ZScoreAdvisoryService.cs`
- Full implementation: mean/stddev computation, z-score calculation, threshold breach detection, price level mapping (REQ-SIZING-008), advisory message generation.

### 9. Updated `RmeModuleExtensions.cs`
- Registered `IPyramidingAdvisoryService` → `PyramidingAdvisoryService` (singleton).
- Registered `IZScoreAdvisoryService` → `ZScoreAdvisoryService` (singleton).

### 10. Created unit tests
- `PyramidingAdvisoryServiceTests.cs` (20 tests): avg entry price, R multiple, combined stop, stop floor, add-on quantity, evaluate scenarios (no action, add, reduce, max entries, stop floor applied).
- `ZScoreAdvisoryServiceTests.cs` (13 tests): edge cases (insufficient data, zero stddev), normal range, add advisory, reduce advisory, price level mapping, custom timeframe, z-score at mean, mean/stddev reporting.
