## Actions Taken

### 1. Created Signal Subscription MongoDB model
- **`apps/api/Signals/SignalSubscriptionDocument.cs`** — typed document class for `signals` collection
  - Core fields: `UserId`, `Name`, `SignalTypeId`, `Timeframe`, `Parameters`
  - Status: `active` / `paused` (pause/resume support via REQ-STRAT-007a)
  - Versioned RME configuration: `Versions[]` array of `RmeConfigurationVersion` records
  - `CurrentVersionIndex` and `PendingVersionIndex` for REQ-STRAT-017b copy-on-write model
  - `RmeConfigurationVersion` nested class with `VersionId`, `VersionNumber`, `RmeConfiguration`, `EffectiveFrom`, `CreatedAt`

### 2. Created repository layer
- **`apps/api/Signals/ISignalSubscriptionRepository.cs`** — interface with CRUD, status management, version operations
  - `GetByUserIdAsync`, `GetByIdAsync`, `GetByIdAndUserAsync`, `CreateAsync`, `ReplaceAsync`, `DeleteAsync`
  - `UpdateStatusAsync` — atomic status toggle (pause/resume)
  - `AddVersionAsync` — append new RME version (copy-on-write)
  - `DiscardPendingVersionAsync` — remove pending version before effective
  - `ActivatePendingVersionAsync` — used by EODSR at run start
  - `GetAllActiveAsync`, `GetActiveByUserAtAsync` — EODSR atomic snapshot queries
- **`apps/api/Signals/MongoSignalSubscriptionRepository.cs`** — MongoDB implementation with typed `IMongoCollection<SignalSubscriptionDocument>`

### 3. Created API endpoints
- **`apps/api/Signals/SignalSubscriptionEndpoints.cs`** — Minimal API endpoints:
  - `GET /api/v1/signals/subscriptions/` — list user's subscriptions (includes `is_paused` flag per REQ-STRAT-007b)
  - `GET /api/v1/signals/subscriptions/{id}` — get single subscription
  - `POST /api/v1/signals/subscriptions/` — create with initial RME version (first version is live immediately)
  - `PUT /api/v1/signals/subscriptions/{id}` — edit signal parameters (name, timeframe, params)
  - `POST /api/v1/signals/subscriptions/{id}/pause` — pause (REQ-STRAT-007a)
  - `POST /api/v1/signals/subscriptions/{id}/resume` — resume (REQ-STRAT-007a/007b)
  - `POST /api/v1/signals/subscriptions/{id}/versions` — create new RME version (REQ-STRAT-017b COW)
  - `GET /api/v1/signals/subscriptions/{id}/versions` — version history with live/pending/superseded status
  - `POST /api/v1/signals/subscriptions/{id}/versions/{versionId}/discard` — discard pending version
  - `DELETE /api/v1/signals/subscriptions/{id}` — delete subscription

### 4. Registered DI and endpoints
- **`apps/api/Signals/SignalSubscriptionExtensions.cs`** — `AddSignalSubscriptionManagement()` DI extension
- **`apps/api/Program.cs`** — added `using SignalStack.Api.Signals`, registered services and endpoints; bumped API version from `v0.4` to `v0.5`

### 5. Created portal UI
- **`apps/web/src/app/(user)/signals/page.tsx`** — Signal Builder page:
  - Lists all user subscriptions with status pills (Active/Paused per REQ-STRAT-007b)
  - Create subscription form (name, signal type, timeframe)
  - Pause/Resume toggle buttons per subscription
  - Version panel: expandable version history table showing live/pending/superseded status
  - New version form (JSON editor for RME configuration with copy-on-write)
  - Discard pending version action
  - Notification banner for success/error feedback
