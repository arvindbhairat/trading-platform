## Actions Taken

### 1. Created `apps/worker/Jobs/HistoricDataSeed/HistoricDataSeedOptions.cs`
Configuration options class bound to `HistoricDataSeed` config section with:
- `PollIntervalSeconds` (default 30) — how often the worker polls for pending jobs
- `HistoricalYearsBack` (default 10) — years of history to fetch per symbol
- `BatchSize` (default 500) — batch size for SQL bulk inserts

### 2. Created `apps/worker/Jobs/HistoricDataSeed/HistoricDataSeedService.cs`
Core service implementing per-symbol seeding:
- **Step 1:** Resolves `sql_table_name_suffix` via `ISymbolTableMapping`
- **Step 2:** Creates D_/W_/M_ tables atomically using `SharedTableDdlTemplate.CreatePerSymbolTablesAsync()` (IF NOT EXISTS — idempotent)
- **Step 3:** Determines resumption point via `IOhlcvRepository.GetLastCandleDateAsync()` — if data exists, fetches from `lastDate + 1` day; otherwise fetches from `historicalYearsBack` ago
- **Step 4:** Fetches daily OHLCV from `IMarketDataProvider.FetchHistoricalOhlcvAsync()`
- **Step 5:** Bulk-inserts daily data into D_ table using temp table + MERGE (skips existing dates)
- **Step 6:** Computes weekly aggregates from D_ via ROW_NUMBER + GROUP BY and MERGEs into W_ table
- **Step 7:** Computes monthly aggregates from D_ via ROW_NUMBER + GROUP BY and MERGEs into M_ table

### 3. Created `apps/worker/Jobs/HistoricDataSeed/HistoricDataSeedWorker.cs`
BackgroundService that:
- Polls `job_runs` collection for records with `job_type: "HDS"` and `outcome: null`
- Supports three ways to specify symbols: explicit `symbols` array, single `symbol` field, or `upload_id` reference to a universe upload
- Falls back to all active (non-archived) symbols if no symbols are specified
- Processes symbols one at a time, updating progress after each
- Marks job as `completed` or `completed_with_errors` with result summary

### 4. Created `apps/worker/Jobs/HistoricDataSeed/HistoricDataSeedExtensions.cs`

## Verification Performed

Since the build environment was unavailable, verification is through reasoned analysis:

| REQ-ID | Verification |
|--------|-------------|
| REQ-HIST-009 | **Per-symbol table materialisation**: `SeedSymbolAsync` calls `SharedTableDdlTemplate.CreatePerSymbolTablesAsync()` inside a SqlTransaction, which creates D_/W_/M_ tables atomically. Verified by code path in `HistoricDataSeedService.cs` lines 74-105. |
| REQ-HIST-009a(a) | **IF NOT EXISTS idempotency**: `SharedTableDdlTemplate.CreateTableIfNotExists()` wraps CREATE TABLE in `IF NOT EXISTS (SELECT 1 FROM INFORMATION_SCHEMA.TABLES ...)`. Second run for same symbol is a no-op for table creation. |
| REQ-HIST-009a(b) | **Atomic transaction**: Table creation wrapped in `SqlTransaction` — commit or rollback. Verified lines 78-105. |
| REQ-HIST-009a(c) | **Shared DDL template**: Uses `SharedTableDdlTemplate.CreatePerSymbolTablesAsync()` from the shared migrations package. |
| REQ-HIST-009 (resumable) | **Resumable from last date**: Calls `IOhlcvRepository.GetLastCandleDateAsync()` to check most recent daily candle. Fetches data from `lastDate.AddDays(1)` onward. Bulk insert uses MERGE to skip already-existing dates. Verified lines 108-110, 261-269. |
| REQ-HIST-009a (idempotent data) | **MERGE insert**: Daily data insertion uses `MERGE ... WHEN NOT MATCHED THEN INSERT` — rows with existing dates are skipped. Weekly/monthly use `MERGE ... WHEN MATCHED THEN UPDATE / WHEN NOT MATCHED THEN INSERT`. |
