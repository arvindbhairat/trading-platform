## Actions Taken

1. **Created `PhaseGateService.cs`** — Core gating validation service that:
   - Reads gate satisfaction status from `sys_config` boolean keys
   - Validates A→B transitions: checks all 5 Phase B gates (legal review, commercial FYERS, SEBI workstream, runbook catalog, SEBI opinion)
   - Validates B→C transitions: checks 3 Phase C gates (SEBI registration granted, commercial legal review, penetration test completed)
   - Provides `RecordSebiOpinionAsync()` to persist opinion metadata to `sys_config` and write an `audit_events` row
   - Provides `SetGateAsync()` to toggle individual gate conditions with audit trail
   - Returns structured `PhaseTransitionResult` with specific gate failure details when blocked

2. **Created `AdminPhaseEndpoints.cs`** — Four new admin API endpoints:
   - `GET /api/v1/admin/phase/gates?target=B|C` — Returns all gates and their pass/fail status
   - `POST /api/v1/admin/phase/transition` — Executes phase transition with full gate validation, step-up auth, justification, and audit event recording
   - `POST /api/v1/admin/phase/sebi-opinion` — Records SEBI classification opinion receipt with lawyer details (document ref, name, SEBI registration number, date)
   - `PATCH /api/v1/admin/phase/gates/{configKey}` — Toggles individual gate conditions (step-up protected)

3. **Updated `SysConfigManifest.cs`** — Added 12 new `sys_config` entries in the `legal` category:
   - `legal.sebi_opinion.*` (5 keys): received, document_ref, lawyer_name, lawyer_sebi_reg, received_date
   - `legal.phase_b.*` (4 keys): legal_review_received, commercial_fyers_configured, sebi_workstream_initiated, runbook_catalog_complete
   - `legal.phase_c.*` (3 keys): sebi_registration_granted, legal_review_commercial, penetration_test_completed

4. **Updated `AdminConfigEndpoints.cs`** — Added intercept for `operations.phase.current` key edits in the generic PUT endpoint, returning a descriptive error that directs the admin to the dedicated phase transition endpoint

5. **Updated `Program.cs`** — Registered `PhaseGateService` as singleton DI service; mapped `AdminPhaseEndpoints`

6. **Updated `docs/system-config.md`** — Documented all 12 new `legal.*` phase gate config keys in the canonical config table
