## Actions taken

### 1. Created new `packages/market-data/SignalStack.MarketData` shared package

The MDP interface contract needs a cross-app home that both the API and Worker service reference. Following the existing `packages/config/` and `packages/migrations/` pattern, created a dedicated `packages/market-data/` package.

Files created:

- **`SignalStack.MarketData.csproj`** — .NET 10.0 project targeting `net10.0`, referencing `SignalStack.Configuration` and `Microsoft.Extensions.DependencyInjection.Abstractions`.

- **`IMarketDataProvider.cs`** — The transport-agnostic interface with three operations:
  - `FetchHistoricalOhlcvAsync(symbol, fromDate, toDate)` — batched historical daily OHLCV
  - `GetLatestQuoteAsync(symbol)` — latest quote (nullable return for unknown symbols)
  - `SubscribeToLivePrices(symbols)` — push-adapter pattern returning `IAsyncEnumerable<QuoteRecord>`
  
  Per ADR-0005, the interface deliberately surfaces no transport semantics (no HttpClient, WebSocket, or RestClient references). The `ProviderName` property is for logging/diagnostics only — never for conditional branching.

- **`OhlcvRecord.cs`** — Provider-agnostic OHLCV record (Symbol, Date, O/H/L/C, Volume).

- **`QuoteRecord.cs`** — Provider-agnostic quote record (Symbol, LastPrice, Change, ChangePercent, TimestampUtc, IsDelayed).

- **`MarketDataProviderType.cs`** — Enum: Fyers, TrueData, GlobalDataFeeds.

- **`MarketDataProviderResolution.cs`** — Resolves active provider from `market_data.provider.active` sys_config key. Case-insensitive. Unrecognised values default to Fyers with a warning log.

- **`MarketDataServiceExtensions.cs`** — DI extension method `AddMarketDataProviderResolution()` registering `MarketDataProviderResolution` as singleton.

### 2. REST-only constraint enforcement (REQ-MARKET-002a/002b)

Created architecture lint tests in `tests/api/SignalStack.Api.Tests/MdpAbstractionLintTests.cs`:

- **`IMarketDataProvider_interface_exists_in_market_data_package`** — Verifies IMarketDataProvider exists with all three required methods.
- **`OhlcvRecord_exists_in_market_data_package`** — Verifies OhlcvRecord DTO exists.
- **`QuoteRecord_exists_in_market_data_package`** — Verifies QuoteRecord DTO exists.
- **`MarketDataProviderType_enum_exists`** — Verifies enum with all three providers.
- **`MarketDataProviderResolution_exists`** — Verifies resolution service references `market_data.provider.active`.
- **`Backend_code_must_not_import_provider_specific_types_outside_adapters`** — Scans `apps/api/` and `apps/worker/` for direct provider-specific patterns (e.g., `api.fyers.in`, `FyersApiClient`) outside exempt adapter namespaces.
- **`Backend_must_not_contain_direct_Fyers_WebSocket_code`** — Verifies no backend code references the FYERS WebSocket (`socket.fyers.in`, `wss://` + fyers) per REQ-MARKET-002b.
- **`IMarketDataProvider_is_transport_agnostic`** — Verifies the interface does not reference HttpClient, WebSocket, RestClient, or tcp.
- **`Provider_resolution_reads_from_sys_config`** — Verifies resolution references all three supported providers and `market_data.provider.active`.
