## Actions Taken

1. **Created `MigrationAttribute.cs`** — `[OneWayMigration]` custom attribute with mandatory `Justification` string for marking irreversible migrations.

2. **Extended `IMongoMigration.cs`** — Added `DownAsync()` default method (throws `NotSupportedException`). Migrations override this with either a proper rollback or a no-op (for idempotent migrations).

3. **Created `MigrationLinter.cs`** — Static validation class enforcing REQ-MIGRATION-003:
   - Rule A: `[OneWayMigration]` with non-empty justification → valid
   - Rule B: Explicit override of `Down()` (FluentMigrator) or `DownAsync()` (IMongoMigration) → valid
   - Otherwise → validation error with explanation

4. **Updated `M001_InitialCollectionCatalogue.cs`** — Added no-op `DownAsync()` override to make it linter-compliant (migration is idempotent: IF-NOT-EXISTS collection creation and index create-with-identical-spec are safe re-runs). Also updated XML doc to document idempotency.

5. **Created `DualReadWindowService.cs`** — Reads `migrations.dual_read_window.active` from MongoDB `sys_config`. Provides:
   - `IsDualReadActiveAsync()` — returns current flag state with 5-min in-memory cache
   - `GetReadModeAsync()` — returns `DualReadMode` enum (`NewSchemaOnly` or `BothPaths`)
   - Fail-safe: defaults to dual-read inactive on any error

6. **Added `migrations.dual_read_window.active` and `migrations.dual_read_window.acknowledged` to `SysConfigManifest.cs`** — Both default to `false`, category `migrations`.

7. **Created `BatchedSchemaMigrationJob.cs`** — Abstract base class in `apps/worker/Jobs/Migrations/` for fleet-wide per-symbol DDL evolution:
   - Iterates all active symbols from symbol master
   - For each symbol, applies per-table DDL via abstract `GetDdlAsync()`
   - Supports `D_`, `W_`, `M_` table prefixes (configurable)
   - Pre/post symbol-batch hooks for setup/teardown
   - Dual-read window awareness via `DualReadWindowService`
   - Resumable: can be restricted to explicit symbol list
   - Error-collecting: collects per-table errors without aborting the batch

8. **Created `MigrationLinterTests.cs`** — Unit tests:
   - `OneWayMigration_with_justification_passes` ✅
   - `OneWayMigration_with_empty_justification_fails` ✅
   - `Migration_with_explicit_rollback_passes` ✅
   - `Migration_without_rollback_and_without_attribute_fails` ✅
   - `ValidateAll_returns_errors_for_invalid_migrations` ✅

9. **Created `DualReadWindowTests.cs`** — Contract tests:
   - Enum defaults and values verified
   - Null-guard on constructor verified
