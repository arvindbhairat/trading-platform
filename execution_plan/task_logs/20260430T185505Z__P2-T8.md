## Actions taken
1. Created `apps/api/Pld/` directory with the following files:
   - **`IPldWebSocketLease.cs`** — Interface defining `TryAcquireAsync`, `TryRefreshAsync`, `ReleaseAsync` plus the result types `PldLeaseAcquireResult` and `PldLeaseRefreshResult`.
   - **`RedisPldWebSocketLease.cs`** — Redis-backed implementation. Acquire uses `SET NX EX` with the key `session:fyers:pld:{userId}`. On conflict (existing lease), reads the previous holder's instance ID, overwrites the key (latest-tab-wins), and returns the previous ID for eviction. Refresh uses a Lua script (GET + PEXPIRE) that only extends TTL if the caller still owns the lease. Release uses a Lua script (GET + DEL) for safe cleanup.
   - **`PldConnectionManager.cs`** — In-memory `ConcurrentDictionary<string, PldConnectionState>` for same-instance eviction. When evicting, sends close code 4001 with the prescribed message. Cross-instance eviction is handled by heartbeat failure.
   - **`PldEndpoints.cs`** — Maps `GET /ws/pld?token=JWT`. Authenticates via JWT in query string (browser WebSocket API limitation). Acquires lease, evicts previous connection if needed, accepts WebSocket, starts heartbeat at half TTL, monitors for client disconnect, and cleans up (removes from connection manager, releases Redis lease).
   - **`PldExtensions.cs`** — DI registration: `AddPldWebSocketServices()` registers `IPldWebSocketLease → RedisPldWebSocketLease` and `PldConnectionManager` as singletons.

2. Modified `apps/api/Program.cs`:
   - Added `using SignalStack.Api.Pld;`
   - Added `builder.Services.AddPldWebSocketServices()` after FYERS token management.
   - Added `app.UseWebSockets(new WebSocketOptions { KeepAliveInterval = TimeSpan.FromSeconds(30) })` before rate limiter.
   - Added `app.MapPldEndpoints()` after FYERS endpoints.
