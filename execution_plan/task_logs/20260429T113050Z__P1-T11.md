## Actions Taken

1. Created `packages/migrations/SignalStack.Migrations/` class library:
   - `IMongoMigration.cs` — migration interface with `Id` and `UpAsync`.
   - `CollectionCatalogueSpec.cs` — static catalogue of all 27 collections with TTL, single-field, and compound index specs; Online Archive flags and archive fields; canonical source of truth for migration + tests.
   - `Migrations/M001_InitialCollectionCatalogue.cs` — migration ID "M001"; creates collections and indexes from `CollectionCatalogueSpec.All`.
   - `MongoMigrationRunner.cs` — discovers, orders, and applies unapplied migrations via `_migrations` tracking collection.
   - `MongoMigrationHostedService.cs` (internal) — `IHostedService` that runs `MongoMigrationRunner.RunAsync()` at startup.
   - `MongoMigrationBootstrapExtensions.cs` — `AddMongoMigrations(string? connectionString, string databaseName)` registers `IMongoClient`, `IMongoDatabase`, runner, and hosted service; validation is lazy (deferred to first `IMongoClient` resolution) to support test environments that remove the hosted service.
   - `atlas-online-archive-policies.json` — companion reference file documenting all 11 Online Archive policies (collection, field, threshold, custom filter where needed) for Atlas console configuration.

2. Wired into `apps/api` and `apps/worker`:
   - Added `ProjectReference` to `SignalStack.Migrations` in both `.csproj` files.
   - Called `AddMongoMigrations(mongoConnectionString, mongoDatabaseName)` in both `Program.cs` files.
   - Connection string: `GetConnectionString("MongoDb")` (env var `ConnectionStrings__MongoDb`); database name: `MongoDB:DatabaseName` config key, default "signalstack".

3. Created `tests/migrations/SignalStack.Migrations.Tests/`:
   - `M001_CollectionCatalogueTests.cs` — 85 lint-style tests covering: all 27 collections present, TTL field/duration/sparse accuracy (4 collections), Online Archive flags (11 collections), Online Archive field names, key unique indexes, required compound indexes (rme_incidents, intent_ledger, trading_calendar), sparse closed_at for positions, atlas policy file exists and covers all archive collections, M001 migration identity.

4. Created `tests/api/SignalStack.Api.Tests/TestApiFactory.cs`:
   - Custom `WebApplicationFactory<Program>` that boots in "Testing" environment, supplies a stub MongoDB connection string, and removes `MongoMigrationHostedService` from DI so existing API tests do not require a live MongoDB.

5. Updated `tests/api/SignalStack.Api.Tests/HealthEndpointsTests.cs` to use `TestApiFactory` instead of `WebApplicationFactory<Program>`.

6. Added both new projects to `SignalStack.sln`.
