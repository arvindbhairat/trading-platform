1. **Created `AdminSystemHealthEndpoints.cs`** — REST API for the system health dashboard:
   - `GET /api/v1/admin/system-health` — returns full system health report with:
     - Per-background-job components (DS, HDS, EODSR, LMDS, LADS, NDJ) with traffic-light status, last run, 7-day daily breakdown sourced from `job_runs` aggregation pipeline
     - Admin FYERS token state (valid/expired/missing) with expiry and 7-day history from `audit_events`
     - Market data provider (active provider, last successful fetch, combined DS+HDS daily breakdown)
     - Telegram delivery pipeline (last successful delivery, 7-day daily breakdown from `notifications`)
     - Global kill switch state (active/inactive, last change timestamp/actor from `audit_events`)
     - Market halt state (halted/clear, auto-detected vs admin-overridden, start timestamp, 7-day history from `audit_events`)
     - Maintenance windows per A-14 spec (pre-market and post-EODSR with IST times)
   - `POST /api/v1/admin/jobs/{jobType}/trigger-manual` — creates a `job_runs` record with `trigger_source=manual` and writes an `audit_events` record for traceability
   - `GET /api/v1/admin/symbol-probe/summary` — returns latest Symbol Validity Probe results with show_banner flag based on configurable threshold

2. **Updated `SysConfigManifest.cs`** — Added 4 new sys_config keys:
   - `operations.system_health.job_stale_after_hours` (default 24) — staleness threshold
   - `operations.system_health.job_error_threshold_pct` (default 10) — error rate threshold
   - `operations.system_health.svp_banner_suppressed` (default false) — banner suppression flag
   - `operations.symbol_probe.flag_threshold_for_banner` (default 5) — minimum flagged symbols for banner

3. **Updated `Program.cs`** — Wired `MapAdminSystemHealthEndpoints()` into the request pipeline

4. **Updated admin home page (`apps/web/src/app/admin/page.tsx`)**:

     - Per-job "Run" button for manual triggering
     - Kill switch status with active/inactive indicator
     - Market halt status with source indicator
     - FYERS token status with expiry
     - MDP active provider with last fetch time
     - Telegram pipeline last delivery time
   - Added Symbol Validity Probe banner (conditionally shown based on flagged symbol count)
   - Added Maintenance Windows card with pre-market and post-EODSR window details
