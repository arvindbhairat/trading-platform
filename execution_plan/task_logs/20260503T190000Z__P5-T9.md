## Actions Taken

1. **Designed and created `TradeLedgerDocument`** — MongoDB document model for the `trade_ledger` collection with all required fields: `TradeId`, `UserId`, `Symbol`, `Side`, `Quantity`, `Price`, `TradeAt`, `OrderId`, `SyncSource`, `IngestedAt`, `LedgerFenceToken`, `IsAdjustment`, `AdjustmentContext`, `Notes`. Immutable by design — no update/delete methods.

2. **Created supporting types** (`TradeIngestionTypes.cs`): `RawTrade` record (input contract), `IngestionResult` record (output summary), `SyncSource` constants (trade_history, intraday, manual_adjustment, seeded_balance).

3. **Implemented `ITradeLedgerRepository` + `MongoTradeLedgerRepository`**:
   - `InsertTradeAsync` — single insert with duplicate-key catch (returns true/false)
   - `InsertTradesAsync` — individual inserts per trade so a duplicate doesn't block subsequent unique trades
   - `TradeExistsAsync` — lookup by `(user_id, trade_id)`
   - `GetTradesByUserAsync` / `GetTradesByUserAndSymbolAsync` — FIFO query support
   - Dedup via compound unique index on `(user_id, trade_id)` — `MongoWriteException` with code 11000 caught at debug level
   - All documents carry `LedgerFenceToken` for stale-write audit

4. **Implemented `TradeIngestionService`** — central ingestion pipeline:
   - **Step 1:** Loads active symbol master (non-archived Nifty 500 symbols) via `ISymbolMasterRepository.GetAllAsync(archived: false)`
   - **Step 2:** For each raw trade, checks `activeSymbolSet.Contains(symbol)` — excluded trades silently logged at trace
   - **Step 3:** Bulk-inserts surviving trades with fencing token, dedup
   - Returns `IngestionResult(Inserted, SkippedDuplicates, SkippedNonNifty500)`

5. **Updated collection catalogue** — Changed `trade_ledger` index from single-field unique(`trade_id`) to compound unique(`user_id`, `trade_id`) per REQ-PORT-023. Updated migration test accordingly.

6. **Wired `TradeIngestionService` into all six sync services:**
   - `OnLoginSyncService` — accepts `rawTrades` + `syncSource` parameters; ingests after lock acquisition, before version increment
   - `ManualAdjustmentService` — new `ExecuteAsync` and `SeedOpeningBalanceAsync` methods; ingests with `isAdjustment: true` and `adjustmentContext`
   - `EodTradeSyncService` — accepts `rawTrades` parameter
   - `ManualSyncService` — accepts `rawTrades` parameter
   - `AdminRebuildService` — accepts `rawTrades` parameter
   - `SingleSymbolBackfillService` — accepts `rawTrades` parameter
   - `LiveAccountDataSyncService` — ingestion step added inside `SyncUserAccountAsync`; `rawTrades` parameter passed through

7. **Created `LedgerWritersExtensions.AddTradeLedgerServices()`** — DI registration for `ITradeLedgerRepository` → `MongoTradeLedgerRepository` and `TradeIngestionService`. Registered in both API and Worker `Program.cs`.
