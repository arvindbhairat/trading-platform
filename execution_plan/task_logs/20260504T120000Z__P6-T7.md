- **`IEquityBaseDivergenceService.cs`** — Interface with `AssessDivergenceAsync` returning `DivergenceAssessment` record.
- **`EquityBaseDivergenceService.cs`** — Implementation:
  - Reads divergence threshold from sys_config (falls back to 15%).
  - Computes divergence ratio: `|FYERS_total − platform_visible| / platform_visible × 100`.
  - Writes `equity_base_divergence_advisory` notification to MongoDB when threshold breached.
  - Notification includes FYERS total, platform-visible equity, gap percentage, and deep-link to profile settings.

### 5. DI registration (`apps/worker/Rme/RmeModuleExtensions.cs`)
- Registered `IEquityBaseDivergenceService → EquityBaseDivergenceService` as singleton.

### 6. Equity profile API extended (`apps/api/Users/UserProfileExtensions.cs`)
- Extended `GET /api/v1/user/profile/equity` to return:
  - `platform_visible_equity` (from equity_curve, with portfolio_snapshots fallback)
  - `external_holdings_excluded` (FYERS total − platform visible)
  - `has_divergence` (boolean — true when gap exceeds threshold)
  - `divergence_gap_pct` (computed gap as percentage)
  - `external_divergence_warn_pct` (current sys_config threshold)

### 7. Unit tests written (`tests/worker/SignalStack.Worker.Tests/EquityBaseDivergenceServiceTests.cs`)
7 tests covering:
- No divergence when values are equal
- Divergence detected when gap exceeds threshold (with notification write verification)
- No divergence when values unavailable (null)
- No notification when gap is below threshold
- Custom threshold from sys_config
- No assessment when platform_visible is zero
- Absolute divergence calculation (handles negative gap)
