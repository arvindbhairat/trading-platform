## Actions Taken
1. **Backend — ISessionRepository** (modified `apps/api/Sessions/ISessionRepository.cs`):
   - Added `StartImpersonationAsync`, `StopImpersonationAsync`, `UpdateImpersonationActivityAsync`.

2. **Backend — MongoSessionRepository** (modified `apps/api/Sessions/MongoSessionRepository.cs`):
   - Implemented StartImpersonationAsync: sets `impersonating_user_id`, `impersonation_started_at`, `impersonation_last_activity_at` (initialized to started_at).
   - Implemented StopImpersonationAsync: unsets all three fields.
   - Implemented UpdateImpersonationActivityAsync: updates `impersonation_last_activity_at`.

3. **Backend — ImpersonationEndpoints** (new `apps/api/Admin/ImpersonationEndpoints.cs`):
   - `POST /api/v1/admin/impersonation/start` — step-up gated (validates StepUpAuthenticatedAt within 5 min window), validates target user exists (admin or user), prevents self-impersonation, records `impersonation_started` audit event with step_up_event_id chain.
   - `POST /api/v1/admin/impersonation/stop` — clears impersonation, records `impersonation_stopped` with duration_seconds.
   - `GET /api/v1/admin/impersonation/status` — returns `active`, `idle_expired`, target user info.
   - All endpoints require `[Authorize]` and admin role check (UserRole.Admin).

4. **Backend — ImpersonationMiddleware** (new `apps/api/Admin/ImpersonationMiddleware.cs`):
   - Runs after SessionValidationMiddleware in pipeline.
   - When session has `ImpersonatingUserId` set: blocks all POST/PUT/PATCH/DELETE (read-only enforcement).
   - Allowlist for `/impersonation/stop` and `/impersonation/status` endpoints.
   - Enforces 15-min idle timeout (auto-stops expired impersonations).
   - Updates `ImpersonationLastActivityAt` on every request during active impersonation.

5. **Backend — Program.cs** (modified `apps/api/Program.cs`):
   - Added `app.UseMiddleware<ImpersonationMiddleware>()` after CsrfMiddleware.
   - Added `app.MapImpersonationEndpoints()` after LegalPosture endpoints.

6. **Frontend — ImpersonationBanner** (new `apps/web/src/components/ImpersonationBanner.tsx`):
   - Client component polling `/api/v1/admin/impersonation/status` every 30s.
   - Prominent "Viewing as {user}" banner with accent="warn" when impersonating.
   - Stop button calls POST `/api/v1/admin/impersonation/stop`.
   - Shows idle-expired state and disables stop button when expired.
   - Returns null when not impersonating (zero UI impact).

7. **Frontend — Admin page** (modified `apps/web/src/app/admin/page.tsx`):
   - Added ImpersonationBanner import and rendering at content top.
   - Added impersonation state management (targetUserId input, start/stop, error display).
   - Added step-up redirect: if impersonation start returns 401 with step_up_required, redirects to auth step-up flow.
   - Added impersonation Card in right column with user ID text input + start/stop buttons.

8. **Frontend — Privacy Policy** (modified `apps/web/src/app/legal/privacy/page.tsx`):
   - Added new section "5. Admin Access to User Data" between data sharing and retention.
   - Discloses read-only admin access, categories of data visible, audit trail recording.
   - Re-numbered sections 4→9 accordingly (sections 4 and 5 swapped; old sections 4→9 became sections 6→9).

9. **Tests — InMemorySessionRepository** (modified `tests/api/SignalStack.Api.Tests/InMemorySessionRepository.cs`):
   - Added StartImpersonationAsync, StopImpersonationAsync, UpdateImpersonationActivityAsync.
   - Follows existing { get; init; } immutable update pattern.
