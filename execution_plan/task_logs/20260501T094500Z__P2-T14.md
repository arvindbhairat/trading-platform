## Actions Taken

### Backend data model
1. **UserDocument.cs** — Added 5 fields: `AcceptedTosVersion`, `AcceptedPrivacyVersion`, `AcceptedTesterAcknowledgementVersion`, `AcceptedMinorDeclaration`, `LegalAcceptedAt` — all BSON-mapped with `[BsonIgnoreIfNull]` for nullable strings.
2. **IUserRepository.cs** — Added `UpdateLegalAcceptanceAsync` method signature.
3. **MongoUserRepository.cs** — Implemented atomic update (6 fields via `Update.Set` chained).

### Backend auth endpoints
4. **AuthEndpoints.cs — GET /api/v1/auth/session/status**: Injected `ISysConfigRepository`. After the deactivated check and before the FYERS check, reads `legal.tos.current_version`, `legal.privacy.current_version`, `legal.tester_acknowledgement.current_version` from `sys_config` and compares against the user's accepted versions. If any version is missing/mismatched or minor declaration is false, returns `pending_acknowledgement` state.
5. **AuthEndpoints.cs — GET /api/v1/auth/legal/versions**: New endpoint returning `{ tos_version, privacy_version, tester_acknowledgement_version }` from sys_config. Authenticated.
6. **AuthEndpoints.cs — POST /api/v1/auth/accept-legal**: New CSRF-protected endpoint. Validates submitted versions match sys_config. Writes 4 distinct `audit_events` rows (`legal_tos_accepted`, `legal_privacy_accepted`, `legal_tester_acknowledgement_accepted`, `legal_minor_declaration_submitted`). Updates user document via `UpdateLegalAcceptanceAsync`. Returns `{ accepted: true }`.
7. **AuthEndpoints.cs** — Added `GetSysConfigStringAsync` helper and `AcceptLegalRequest` record.
8. **AuthEndpoints.cs** — Updated test-token endpoint to pre-set legal acceptance so existing tests pass.

### Frontend
9. **accept-legal/page.tsx** — New page at `/accept-legal`. Fetches legal versions on mount. Shows 4 checkboxes (ToS, Privacy, Tester Acknowledgement, 18+ declaration). Submit calls `POST /api/v1/auth/accept-legal`, then `fetchSessionStatus()` to route to next lifecycle screen.
10. **auth/callback/page.tsx** — Changed `pending_acknowledgement` routing from `/login?error=acknowledgement_required` to `/accept-legal`.
11. **login/page.tsx** — Updated text from placeholder to indicate acceptance happens after sign-in.
