## Actions Taken

### 1. Notification type added (`apps/api/Notifications/NotificationType.cs`)
- Added `SymbolArchivedWithOpenPosition = "symbol_archived_with_open_position"` constant to the user-facing notification types.
- Added to the `UserFacing` HashSet so it passes `NotificationType.IsValid()` and is available for portal display per REQ-NOTIFY-006.

### 2. LMDS archive + scan-exclusion filtering (`apps/worker/Jobs/LiveMarketScan/LiveMarketScanService.cs`)
- Added `ISymbolMasterRepository` as a constructor dependency (worker already registers `UniverseManagement` services).
- In `ExecuteCycleAsync`, after loading active positions (Step 1), added a filtering step (Step 1b) that loads the symbol master and builds a set of symbols that are either `IsArchived` or `ScanExcluded`.
- Positions whose symbols are in the exclusion set are removed from the scan cycle.
- Added `GetExcludedSymbolsAsync` helper that loads all symbols and returns a `HashSet<string>` of excluded symbols.
- Logs count of excluded positions; returns empty result if all positions are excluded.

### 3. Notification generation on archive (`apps/api/Universe/UniverseSyncEndpoints.cs`)
- Added `using SignalStack.Api.Notifications;` for `INotificationWriter` and `NotificationDocument` access.
- **Commit endpoint** (`POST /upload/commit`): After successful commit and audit recording, if `result.ArchivedSymbols.Count > 0`, calls `NotifyArchivedSymbolOpenPositionsAsync` to check for open positions and generate notifications.
- **Work-queue resolve** (`POST /work-queue/{id}/resolve`, `mark_delisting` case): After archiving the symbol, calls `NotifyArchivedSymbolOpenPositionsAsync` for the single symbol. Replaced the existing `// Note: symbol_archived_with_open_position notification is deferred to P5-T16` TODO comment.
- Added `NotifyArchivedSymbolOpenPositionsAsync` static helper method that:
  - Queries the `positions` collection for `PendingEntry`/`Open`/`Suspended` positions matching the archived symbols.
  - Groups by `user_id`.
  - For each user with an open position, creates a `symbol_archived_with_open_position` notification with the prescribed content per REQ-UNIV-015.
  - Writes batch through `INotificationWriter.WriteBatchAsync`.
  - Wraps in try/catch so notification failures are non-fatal — archive has already been committed.
