## Actions Taken

### 1. SQL Migration (`AddBacktestMetrics_003.cs`)
- Added 20 columns to `BT_RunHeaders`:
  - `metrics_json` (NVARCHAR MAX) — full JSON blob of all computed metrics + equity curve
  - `starting_equity`, `ending_equity` (DECIMAL)
  - `total_return_pct`, `total_return_absolute` (DECIMAL)
  - `sortino_ratio`, `recovery_factor` (DECIMAL)
  - `average_r`, `adjusted_expectancy`, `max_drawdown_in_r` (DECIMAL)
  - `low_confidence` (BIT)
  - `universe_coverage_pct` (DECIMAL)
  - `total_trades`, `winning_trades`, `losing_trades`, `skipped_sessions`, `total_sessions` (INT)
  - `survivorship_bias_discount_pct`, `raw_expectancy` (DECIMAL)
  - `rme_config_json` (NVARCHAR MAX)

### 2. Backend: BacktestModels.cs
- Added `RmeConfigurationJson` property to `BacktestRunResult`

### 3. Backend: BacktestEngine.cs
- Wired `RmeConfigurationJson` from options through to the result construction

### 4. Backend: SqlBacktestRepository.cs
- `SaveRunHeaderAsync`: stores all new columns + serializes full metrics as JSON in `metrics_json`
- `GetRunAsync`: fully implemented — reads `BT_RunHeaders` header row, then reads trades from `BT_Trades`; deserializes equity curve from `metrics_json`
- Added `ReadRunHeader(SqlDataReader)` and `ReadTrade(SqlDataReader)` static helpers

### 5. Backend: BacktestEndpoints.cs
- Added `POST /api/v1/backtest/run-from-subscription/{subscriptionId}` endpoint
  - Loads subscription from MongoDB, validates user ownership
  - Reads `strategies.backtest.default_starting_equity_inr` from sys_config when equity not explicitly provided (REQ-BTSTORE-006a)
  - Pins RME configuration from the subscription's current live version (REQ-BTSTORE-003)
  - Falls back to sensible slippage (0.1%) and commission (0.01%) defaults
- `RunBacktestAsync`: added `ISysConfigRepository` dependency for default equity lookup
- Added `RunFromSubscriptionRequest` DTO

### 6. Seed: SysConfigManifest.cs
- Added `strategies.backtest.default_starting_equity_inr` (number, default 1000000)

### 7. Frontend: Backtest Results page (`apps/web/src/app/(user)/backtest/[runId]/page.tsx`)
- Full results page with:
  - Header: signal type, date range, slippage/commission details
  - Low-confidence badge and survivorship-adjusted badge
  - Notional default caveat banner (REQ-BTSTORE-006a)
  - Version pinning info banner (REQ-BTSTORE-003)
  - Primary KPI strip (5 cards): Total Return, Sharpe, Max DD, Win Rate, Avg R
  - Secondary KPI row (4 cards): Sortino, Recovery Factor, Expectancy (R), Profit Factor
  - SVG equity curve chart with Nifty 500 benchmark line overlay, gradient fill, grid
  - Summary stats: total trades, winning/losing, universe coverage
  - Trade table with all columns (symbol, entry/exit dates, prices, R multiple, net PnL, exit reason)

### 8. Frontend: Signal Builder page (`apps/web/src/app/(user)/signals/page.tsx`)
- Added "Backtest" button (icon="bar-chart", variant="secondary") to each subscription card's action row
- Added backtest configuration panel (expandable per subscription):
  - Date range start/end pickers
  - Optional starting equity input
  - "Run Backtest" submit button
- Added `handleRunBacktest(subId)` function:
  - Calls `POST /api/v1/backtest/run-from-subscription/{subId}`
  - Navigates to `/backtest/{runId}` on success
  - Error handling with alert fallback
