## Actions Taken

1. **Added `SignalsSuspended` field to `UserDocument.cs`** — boolean, default false, BsonElement `signals_suspended`, for tracking per-user signal suspension (REQ-ADMIN-010).

2. **Added `SetSignalsSuspendedAsync` to `IUserRepository.cs`** — method signature for toggling per-user signal suspension.

3. **Implemented `SetSignalsSuspendedAsync` in `MongoUserRepository.cs`** — MongoDB update that sets `signals_suspended` boolean and `updated_at`.

4. **Created `AdminKillSwitchEndpoints.cs`** — step-up gated admin endpoints:
   - `GET /api/v1/admin/kill-switch` — reads `risk.kill_switch.active` from sys_config (no step-up required).
   - `POST /api/v1/admin/kill-switch/activate` — writes audit event, sets sys_config to true.
   - `POST /api/v1/admin/kill-switch/deactivate` — writes audit event, sets sys_config to false.
   - Shared `ToggleKillSwitchAsync` with admin role check, step-up validation (5-min window via session.StepUpAuthenticatedAt), and audit-before-mutation pattern.

5. **Created `AdminSignalTypeEndpoints.cs`** — step-up gated admin endpoints:
   - `GET /api/v1/admin/signal-types` — lists known types (ma_crossover) with enabled/disabled status.
   - `POST /api/v1/admin/signal-types/{signalTypeId}/disable` — writes audit event, sets `risk.signal_types.{id}.enabled` to false in sys_config (upsert).
   - `POST /api/v1/admin/signal-types/{signalTypeId}/enable` — writes audit event, sets sys_config key to true (upsert).
   - Shared `ToggleSignalTypeAsync` with validation against KnownSignalTypes, step-up gate, and audit.

6. **Created `AdminPositionEndpoints.cs`** — step-up gated admin endpoints:
   - `POST /api/v1/admin/positions/{positionId}/suspend` — sets state to Suspended with suspension_reason=manual_admin_suspension and suspension_source=ADMIN.
   - `POST /api/v1/admin/positions/{positionId}/release` — releases only ADMIN-sourced suspensions; restores to Open (if entry_price > 0) or PendingEntry (if zero/null entry_price). Rejects non-ADMIN suspension sources (e.g. LMDS, RME_OCC, CORPORATE_ACTION).
   - `POST /api/v1/admin/positions/{positionId}/force-close` — transitions from Open or Suspended to Closed with reason admin_forced_close.
   - Shared `ModifyPositionStateAsync` handles suspend/force-close with state transition validation.

7. **Registered endpoint groups in `Program.cs`** — added `MapAdminKillSwitchEndpoints()`, `MapAdminSignalTypeEndpoints()`, and `MapAdminPositionEndpoints()` after existing admin endpoint registrations.

8. **Added sys_config seed entries to `SysConfigManifest.cs`**:
   - `risk.kill_switch.active` (boolean, false) — REQ-ADMIN-007.
   - `risk.signal_types.ma_crossover.enabled` (boolean, true) — REQ-ADMIN-011.

9. **Updated `docs/system-config.md`** — added seed table rows for both new sys_config keys.
