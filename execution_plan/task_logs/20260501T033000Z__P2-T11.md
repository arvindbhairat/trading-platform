## Actions Taken

### API Changes (apps/api)

1. **Extended `ISysConfigRepository`** (`apps/api/SysConfig/ISysConfigRepository.cs`):
   - Added `ListAllAsync(string? category, CancellationToken)` — returns all entries, optionally filtered
   - Added `GetByKeyAsync(string key, CancellationToken)` — returns single entry
   - Added `UpdateAsync(string key, BsonValue newValue, string updatedByUserId, CancellationToken)` — updates value/increments version
   - Added `ResetToDefaultAsync(string key, string updatedByUserId, CancellationToken)` — resets to default value
   - Added `ListCategoriesAsync(CancellationToken)` — returns distinct categories

2. **Implemented in `MongoSysConfigRepository`** (`apps/api/SysConfig/MongoSysConfigRepository.cs`):
   - All new methods with proper MongoDB driver usage
   - FindOneAndUpdate for atomic update with ReturnDocument.After
   - DistinctAsync for category listing
   - Each mutation updates `updatedAt`, `updatedByUserId`, and increments `version`

3. **Created `AdminConfigEndpoints.cs`** (`apps/api/Admin/AdminConfigEndpoints.cs`):
   - `GET /api/v1/admin/config` — list all entries with optional `?category=` filter
   - `GET /api/v1/admin/config/categories` — list distinct categories
   - `GET /api/v1/admin/config/{key}` — get single entry
   - `PUT /api/v1/admin/config/{key}` — update entry value (step-up check for risk/legal/operations)
   - `POST /api/v1/admin/config/{key}/reset` — reset to default (step-up check for risk/legal/operations)
   - Step-up validation: checks `session.StepUpAuthenticatedAt` is within 5-minute window
   - Audit events written BEFORE mutation (`config_updated` / `config_reset`)
   - Sensitive categories: `risk`, `legal`, `operations`
   - Request validation: checks `isEditable` flag, validates value types against `valueType`
   - BSON value conversion handles string/number/boolean types properly

4. **Registered endpoints in `Program.cs`**:
   - Added `using SignalStack.Api.Admin`
   - Added `app.MapAdminConfigEndpoints()` before `app.Run()`

### Web Changes (apps/web)

5. **Added nav item** (`apps/web/src/components/primitives.tsx`):
   - Added `{ id: "config", label: "Config", icon: "settings" }` to `adminNavItems`

6. **Created admin config page** (`apps/web/src/app/admin/config/page.tsx`):
   - Full client component with Shell, admin nav items
   - Fetches config entries and categories from API on load
   - Category filter dropdown
   - Responsive table: Category, Key, Value, Default, Description, Actions columns
   - Category badges with warning tone for sensitive categories
   - Value display with boolean pills
   - Inline edit panel with type-aware input (text/boolean/number)
   - Reset to default with confirmation card
   - Step-up flow: checks `SessionStatus.step_up.valid` and initiates OAuth step-up redirect
   - Notification banner for success/error messages
   - Saves `returnTo` in sessionStorage before step-up redirect

7. **Fixed pre-existing bug** (`apps/web/src/app/layout.tsx`):
   - Moved `Metadata` import from `"react"` to `"next"` (was blocking build)
