## Actions Taken

1. **Created `InMemorySignalSubscriptionRepository`** (`tests/api/SignalStack.Api.Tests/InMemorySignalSubscriptionRepository.cs`):
   - ConcurrentDictionary-based implementation of `ISignalSubscriptionRepository`.
   - Full contract: CRUD, pause/resume, versioned copy-on-write, active-by-user-at snapshot.
   - Follows existing in-memory repository pattern (InMemoryFyersTokenRepository, InMemoryUserRepository).

2. **Created `SignalSubscriptionIntegrationTests`** (`tests/api/SignalStack.Api.Tests/SignalSubscriptionIntegrationTests.cs`):
   - 15 integration tests covering full Signal Subscription lifecycle: create, list, get-by-id, update, pause, resume, add version, list versions, discard pending version, delete, delete-then-list-empty, unauthenticated 401.
   - Uses `AuthTestApiFactory` + `WithWebHostBuilder` to inject `InMemorySignalSubscriptionRepository`.
   - Validates REQ-STRAT-007a/007b (create/list/get/update/pause/resume) and REQ-STRAT-017b (versioned copy-on-write).

3. **Created `AdminKillSwitchTests`** (`tests/api/SignalStack.Api.Tests/AdminKillSwitchTests.cs`):
   - 4 tests verifying step-up gating (REQ-SEC-011): activate/deactivate without step-up → 401, non-admin → 403, activate with step-up → not 401/403.
   - Uses `UpsertAdminOnSignInAsync`, forged JWTs, `UpdateStepUpAsync`.

4. **Created Playwright E2E scaffolding:**
   - `tests/e2e/playwright.config.ts` — Chromium project, 30s timeout, `PLAYWRIGHT_BASE_URL` configurable via env.
   - `tests/e2e/health-check.e2e.ts` — 3 smoke tests: home page loads with baseline text, login page accessible, API health endpoint reachable.
   - `tests/e2e/package.json` — `@playwright/test` dependency.

5. **Wired E2E tests into CI** (`.github/workflows/ci.yml`):
   - New `e2e` job: installs Playwright, builds web app, starts Next.js dev server, runs Playwright smoke tests.
   - API health check hits the API port directly (configurable via `E2E_API_BASE_URL`).

6. **Added regression coverage gate to CI** (`.github/workflows/ci.yml`):
   - Dotnet test step now enforces 70% line coverage threshold via `/p:Threshold=70 /p:ThresholdType=line`.
   - Vitest thresholds raised from `lines: 1, statements: 1` to `lines: 45, statements: 45` to match existing `functions: 45` baseline — enforces no regression below current coverage.
