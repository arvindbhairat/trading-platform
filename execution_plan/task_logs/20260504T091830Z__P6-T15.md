## REQ Coverage Attempted

No explicit REQ-IDs listed in `execution_plan.md` for P6-T15. The task implements:
- `portfolio-risk-guidelines § Stop Loss Types` — ATR-based trailing stop.
- ADR-0003 carve-out — trailing-stop updates applied synchronously (not routed through per-position channel).
- REQ-RME-CONC-005 — EOD trailing-stop wired as event producer.

## Actions Taken

1. **Created `AtrTrailingStopLoss`** (`apps/worker/Rme/AtrTrailingStopLoss.cs`):
   - Implements `IStopLoss` with `Name = "AtrTrailingStop"`.
   - Combines ATR-based distance (`AtrValue × AtrMultiplier`) with trailing-stop semantics (trails from highest price since entry).
   - Falls back to `DefaultFixedStopDistancePct` when ATR is unavailable.
   - Handles degenerate inputs (zero/negative highest price, zero/negative ATR).
   - Clamps stop below highest price (1% minimum).
   - Stateless and thread-safe (singleton registration).

2. **Created `TrailingStopSyncService`** (`apps/worker/Rme/TrailingStopSyncService.cs`):
   - Concrete implementation of `ITrailingStopSyncService`.
   - Uses `AtrTrailingStopLoss` for all calculations (resolved by name from `IEnumerable<IStopLoss>`).
   - **ADR-0003 carve-out:** Updates are applied synchronously via `IPositionRepository.UpdateWithOccAsync` — NOT routed through the per-position channel.
   - **Non-decreasing invariant:** New stop price must be strictly higher than the existing trailing stop on the position document (skip when lower or equal).
   - **OCC safety:** Uses optimistic concurrency control via `_version` field; OCC conflicts are logged and deferred to next EOD cycle.
   - Handles edge cases: position not found, existing trailing stop is zero (first recalculation).

3. **Updated `RmeModuleExtensions`** (`apps/worker/Rme/RmeModuleExtensions.cs`):
   - Registered `AtrTrailingStopLoss` as `IStopLoss` (singleton).
   - Replaced `NoOpTrailingStopSyncService` with `TrailingStopSyncService` as `ITrailingStopSyncService`.

4. **Created tests** (`tests/worker/SignalStack.Worker.Tests/`):
   - `AtrTrailingStopLossTests.cs` — 19 tests covering: standard ATR calculation, custom multiplier, null/zero/negative ATR fallback, highest price from inputs vs entry fallback, zero/negative highest price, wide/narrow ATR, above-entry stop (price moved up), clamping, rounding, large prices, wrong-type inputs.
   - `TrailingStopSyncServiceTests.cs` — 9 tests covering: full recalculation of all non-terminal positions, non-decreasing invariant (skip when not increased, update when increased), first recalculation with zero existing stop, OCC conflict handling, position-not-found no-op, correct calculator input verification, current-price-as-highest, missing-registration guard.
