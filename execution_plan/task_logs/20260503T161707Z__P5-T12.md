## Actions Taken

1. Created `apps/worker/Jobs/LiveMarketScan/LiveMarketScanOptions.cs` — Configuration model with `PollIntervalSeconds` (90), `CapacityWarnPct` (80), `MaxPositionsPerCycle` (500), `StaleQuoteCircuitThreshold` (3).

2. Created `apps/worker/Jobs/LiveMarketScan/LiveMarketScanService.cs` — Core scanning logic:
   - Loads active (non-terminal) positions from MongoDB positions collection
   - Collates unique symbols for quote fetching
   - Fetches live quotes via `IMarketDataProvider.GetLatestQuoteAsync` per symbol
   - Evaluates each position against current price for stop, trailing-stop, add, and reduce level breaches
   - Enqueues `PriceLevelBreachedEvent` to `IPositionChannelRegistry` when levels breached
   - Tracks stale quote cycles for circuit-clear detection per REQ-PLC-004
   - Reports capacity warning when cycle exceeds `CapacityWarnPct` of poll interval (REQ-SLO-004/011)
   - OTEL metrics: `lmds.scan.cycles.total`, `lmds.breaches.detected.total`, `lmds.scan.cycle.duration_ms`, `lmds.positions.scanned_per_cycle`

3. Created `apps/worker/Jobs/LiveMarketScan/LiveMarketScanWorker.cs` — BackgroundService following LADS pattern:
   - Polls at configured interval (default 90s)
   - Checks NSE market hours via `ITradingCalendarRepository` before each cycle (REQ-STOP-006a)
   - Creates DI scope per cycle, delegates to `LiveMarketScanService`
   - Graceful error handling per existing patterns

4. Created `apps/worker/Jobs/LiveMarketScan/LiveMarketScanExtensions.cs` — DI registration:
   - `BindConfiguration` → `ValidateDataAnnotations` → `ValidateOnStart`
   - Registers `LiveMarketScanService` as singleton
   - Registers `LiveMarketScanWorker` as hosted service

5. Updated `apps/worker/Program.cs` — Added `builder.Services.AddLiveMarketScan(builder.Configuration)` after LADS registration.

6. Updated `apps/worker/appsettings.json` — Added `LiveMarketScan` config section with defaults.
