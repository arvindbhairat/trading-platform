## Conflict Found

`InMemorySessionRepository.UpdateStepUpAsync` had a latent bug: the `stepUpEventId` parameter was accepted but never assigned to the new `SessionDocument`. This didn't surface in earlier tests because no prior endpoint used `StepUpEventId` after step-up validation. P8-T12's audit event recording (`RecordStepUpGatedAsync` with `session!.StepUpEventId!.Value`) exercised this path and threw `InvalidOperationException`. Fixed by adding `StepUpEventId = stepUpEventId` in the `UpdateStepUpAsync` method of `InMemorySessionRepository`.
