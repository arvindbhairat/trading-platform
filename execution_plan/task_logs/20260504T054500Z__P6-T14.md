## Actions Taken
1. Created `apps/worker/Rme/TrailingStopLoss.cs`:
   - Implements `IStopLoss` with `Name = "TrailingStop"`
   - Uses `StopLossInput.TrailingStopPercent` (first-class field) or falls back to `RmeModuleOptions.DefaultTrailingStopPercent`
   - Reads `HighestPriceSinceEntry` from `AdditionalInputs` for the highest price observed since entry
   - Computes stop price as `HighestPriceSinceEntry × (1 - TrailingPercent / 100)`
   - Falls back to entry price when no highest price is provided
   - Guards against zero/negative highest price (falls back to entry)
   - Guards against zero/negative trailing percent (falls back to default)
   - Unlike Fixed/ATR stops, does **not** clamp to below entry price — a trailing stop can legitimately be above entry when the price has moved up; instead clamps against the highest price
   - Rounds to 2 decimal places; stateless and thread-safe singleton

2. Added `DefaultTrailingStopPercent` to `RmeModuleOptions`:
   - Default: `10.0` (10% trailing stop)
   - Range: `0.1–50.0`
   - Mapped from sys_config category

3. Registered `TrailingStopLoss` in DI via `RmeModuleExtensions.cs`:
   - Added `services.AddSingleton<IStopLoss, TrailingStopLoss>()`

4. Created `tests/worker/SignalStack.Worker.Tests/TrailingStopLossTests.cs`:
   - 16 unit tests covering:
     - Standard trail calculation (entry=1000, highest=1200, 10% → 1080)
     - Explicit trailing percent from input
     - Default trailing percent from options when input is null
     - Higher highest price → stop trails higher
     - Fallback to entry price when highest price not provided
     - Fallback when highest price is zero
     - Fallback when highest price is negative
     - Fallback from zero trailing percent to default
     - Stop is always below highest price
     - Clamp guard as safety net (degenerate inputs)
     - Positive stop for all valid inputs
     - Name property returns "TrailingStop"
     - Rounding to 2 decimal places
     - Large price handling
     - Wrong-type AdditionalInputs ignored
     - Small trailing percentage
