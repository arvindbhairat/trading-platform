### REQ-RME-006a verification
- Primary source: `equity_curve` collection → equity value read directly, source = `AutoDerived`
- Fallback: `portfolio_snapshots` (current_market_value + cash_reserve) when equity_curve has no record

### REQ-RME-006b verification
- `EquityBaseResult` includes `FyersTotalAccountValue` (total from equity_curve or snapshots)
- `PlatformVisibleEquity` equals user-visible equity (same as `EquityBase` when auto-derived, auto-derived value when override is active)
- `ExternalHoldingsExcluded` tracks excluded value (override delta when override is active)

### REQ-RME-006c verification
- Manual override read from `users.equity_base_override` field
- Override stale when `equity_base_override_updated_at` > 30 days old (threshold from `risk.equity_override_stale_days` sys_config)
- API endpoints: GET/PUT/DELETE `/api/v1/user/profile/equity/override`
- S-10 cap: `min(FYERS_total × 1.5, FYERS_total + ₹10,00,000)` enforced on PUT
- Audit trail recorded for override mutations

### REQ-RME-006d verification
- V1 read: capture `ledger_snapshot_version` before equity read
- V2 read: capture `ledger_snapshot_version` after equity read
- V1 == V2 → snapshot consistent, return result immediately
- V1 != V2 → retry (up to `SnapshotRetryMaxAttempts`), with `SnapshotRetryBackoffMs` delay
- Retry exhausted:
  - Override active → RME-R1: "Your equity override is in effect, and we are retrying"
  - No override → generic: "Portfolio state is updating. Please try again."
