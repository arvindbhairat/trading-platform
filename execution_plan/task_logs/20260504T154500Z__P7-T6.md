### REQ-ORDER-014a Verification

The `IntentSigningService.CreateSignedPayloadAsync` method now:
1. Computes HMAC and generates nonce (existing step 10-11)
2. Constructs an `IntentLedgerDocument` with all required fields set
3. Persists it via `IIntentLedgerRepository.CreateIntentAsync` (new step 11b)
4. Returns the `SignedPayloadResponse` only after the write succeeds
