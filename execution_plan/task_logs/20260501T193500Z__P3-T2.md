## Actions Taken

### Created files
1. **`apps/api/Universe/SymbolMasterDocument.cs`** — MongoDB document model for the `symbol_master` collection. Fields: `symbol`, `company_name`, `industry`, `series`, `isin`, `sql_table_name_suffix`, `lot_size` (default 1), `is_archived`, `scan_excluded`, `created_at`, `updated_at`.

2. **`apps/api/Universe/ISymbolMasterRepository.cs`** — Repository interface with methods: `GetAllAsync`, `FindBySymbolAsync`, `FindByIsinAsync`, `FindBySuffixAsync`, `GetAllSuffixesAsync`, `CreateAsync`, `UpdateMetadataAsync`, `BulkCreateAsync`, `CountAsync`, `HasConflictAsync`.

3. **`apps/api/Universe/MongoSymbolMasterRepository.cs`** — MongoDB implementation of `ISymbolMasterRepository`.

4. **`apps/api/Universe/SqlTableNameSuffixGenerator.cs`** — Deterministic suffix generator implementing REQ-HIST-006/007:
   - Uppercase → replace non-[A-Z0-9] with `_` → collapse consecutive `_` → strip leading/trailing `_` → truncate 100 chars
   - Digit-leading symbols prefixed with `SYM_` (REQ-HIST-007)
   - Empty result throws `ArgumentException` with operator error message

5. **`apps/api/Universe/SymbolMasterEndpoints.cs`** — API endpoints under `/api/v1/universe/`:
   - `GET /symbols` — list all symbols with optional `?archived=` filter
   - `GET /symbols/{symbol}` — find by trading symbol
   - `POST /symbols` — create with suffix generation + collision check + uniqueness validation
   - `PATCH /symbols/{symbol}` — update mutable fields (industry, is_archived, scan_excluded)
   - `GET /count` — count with optional archive filter

6. **`apps/api/Universe/UniverseExtensions.cs`** — DI registration extension method (`AddUniverseManagement`).

7. **`apps/worker/Hosting/SymbolMasterCollisionGuard.cs`** — Worker startup guard (REQ-HIST-008a):
   - Reads all suffix values from `symbol_master`
   - Groups for duplicates
   - Extracted `FindCollisions` as public static method for unit-testability

### Modified files
8. **`apps/api/Program.cs`** — Added `using SignalStack.Api.Universe`, `builder.Services.AddUniverseManagement()`, endpoint mapping at `/api/v1/universe`.

9. **`apps/worker/Program.cs`** — Added `SymbolMasterCollisionGuard` singleton registration and startup invocation after seed version guard.
