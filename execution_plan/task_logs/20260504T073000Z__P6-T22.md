## Actions Taken

### Backend — PortfolioImpactService + API endpoint

1. Created `apps/api/Portfolio/PortfolioImpactService.cs` — service that:
   - Reads non-terminal positions (Open, PendingEntry, Suspended) from the MongoDB `positions` collection
   - Reads account equity from the `equity_curve` collection (latest entry), with fallback to `portfolio_snapshots`
   - Reads `risk.default.max_portfolio_heat_pct` from sys_config via `ISysConfigRepository`
   - Reads `risk.correlated_industry_groups` from sys_config for sector mapping
   - Reads industry classification per symbol from the `symbol_master` collection
   - Computes:
     - **Total Open Risk** = Σ(max(0, EntryPrice − StopLoss)) × Quantity across all active positions
     - **Portfolio Heat** = Total Open Risk / Account Equity × 100%
     - **Sector exposure breakdown** grouped by correlated industry group (with "Other" fallback)
     - **Entry blocked** flag when heat ≥ max heat threshold
   - Includes `PortfolioImpactResult` and `SectorExposureItem` records
   - Includes `CorrelatedIndustryGroupRecord` for sys_config JSON deserialization

2. Modified `apps/api/Portfolio/PortfolioEndpoints.cs` — added `GET /api/v1/portfolio/impact` endpoint returning camelCase JSON response with all impact fields.

3. Modified `apps/api/Portfolio/PortfolioExtensions.cs` — registered `PortfolioImpactService` as singleton.

### Frontend — PortfolioImpactPanel component

4. Created `apps/web/src/components/PortfolioImpactPanel.tsx` — React component that:
   - Fetches from `GET /api/v1/portfolio/impact` on mount
   - Auto-refreshes every 60 seconds
   - Shows loading, error, and empty-data states
   - Displays a **heat gauge** bar with color coding (green < 80%, amber 80–99%, red ≥ 100% of max)
   - Shows open positions count + total open risk
   - Shows suspended-position count warning when applicable
   - Lists sector exposure bars with series colors
   - Shows a red entry-blocked warning banner when heat limit is reached
   - Uses the existing design system tokens (`var(--up-500)`, `var(--warn-500)`, `var(--down-500)`, etc.) and primitives (`Label`, `Num`)

5. Modified `apps/web/src/app/(user)/chart/page.tsx` — replaced the static placeholder text ("Open risk and sector exposure will appear once portfolio data is loaded.") with the `<PortfolioImpactPanel />` component.
