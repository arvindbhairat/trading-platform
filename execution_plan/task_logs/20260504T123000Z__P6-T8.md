## Actions taken

1. **Created `FixedPercentageSizingModel`** (`apps/worker/Rme/FixedPercentageSizingModel.cs`):
   - Implements `ISizingModel` with `Name = "FixedPercentage"`.
   - Reads `DefaultRiskPerTradePct` from `RmeModuleOptions` via `IOptions<RmeModuleOptions>`.
   - Computes `riskAmount = equityBase * (riskPct / 100)` and `RecommendedQuantity = floor(riskAmount / entryPrice)`.
   - Returns `SizingResult` with model identity and computed values. Stateless, thread-safe, singleton-safe.

2. **Registered in DI** (`apps/worker/Rme/RmeModuleExtensions.cs`):
   - Added `services.AddSingleton<ISizingModel, FixedPercentageSizingModel>()` under a new P6-T8 section.

3. **Refactored `RmeAdvisoryService.GetSizingRecommendationAsync`**:
   - Injected `IEnumerable<ISizingModel>` and removed now-unused `IOptions<RmeModuleOptions>`.
   - Dispatches to the matching model by `sizingModelType` (case-insensitive), falling back to `FixedPercentageSizingModel`.
   - Constructs `SizingInput` from equity base result and delegates `Calculate` to the resolved model.
   - Maps `SizingResult` → `SizingAdvisory`.

4. **Fixed downstream test** (`EquityBaseReaderTests.cs`):
   - Updated two `RmeAdvisoryService` instantiations to pass `IEnumerable<ISizingModel>` with a `FixedPercentageSizingModel` instance.
   - Updated assertion to expect `"FixedPercentage"` instead of the old pass-through `"fixed_percentage"`.

5. **Wrote unit tests** (`tests/worker/SignalStack.Worker.Tests/FixedPercentageSizingModelTests.cs`):
   - 8 tests covering: default 0.5% risk, custom 1.0% risk, zero entry price, Name property, large equity (10 Cr), small equity (fractional floor), minimum risk (0.1%), and fractional quantity flooring.
