# User Portal — UI Kit

The trader-facing surface of Signal Stack. Dark, dense, mobile-friendly. Built with React + Babel (via JSX) so components stay modular.

## Components

- `AppShell.jsx` — 3-zone shell: top bar, left sidebar (desktop), bottom tabs (mobile), content.
- `Dashboard.jsx` — KPI strip, open positions table, notification feed, equity curve.
- `ChartPage.jsx` — TradingView-style chart pane with RME advisory panel.
- `SignalBuilder.jsx` — Signal Subscription create/edit flow.
- `OrderModal.jsx` — FYERS handoff confirmation with legal disclaimer strip.

Open `index.html` for the interactive demo. Switch views from the sidebar.
