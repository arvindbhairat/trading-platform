# Admin Portal — UI Kit

The admin console. Same shell as the user portal, with an extra admin menu.

## Components
- `AdminShell.jsx` — admin-flavored shell (reuses primitives).
- `AdminHome.jsx` — Legal Posture widget, system health, pending approvals.
- `UserApprovals.jsx` — approval queue with Phase A tester ceiling.
- `UniverseManagement.jsx` — Nifty 500 CSV upload + symbol list.
- `JobRuns.jsx` — DataSync / EODSR / LMDS / LADS / NDJ run history.
