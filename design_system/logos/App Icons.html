App icon set

Signal Stack icons

Full app-icon set derived from the Signal Stack mark — ascending bars with a signal indicator. Includes master SVGs, PNG renders at every standard size, a multi-resolution favicon.ico, a maskable variant for Android adaptive icons, and a Web App Manifest.
